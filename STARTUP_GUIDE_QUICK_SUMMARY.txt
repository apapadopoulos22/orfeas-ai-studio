ORFEAS AI - QUICK STARTUP GUIDE
================================================================================

PROBLEM FIXED: Windows Path Separator Error
  - Issue: "Model path not exists" causing 15-30 minute startup delays
  - Cause: Mixed path separators (C:\..\..\tencent/Hunyuan3D-2)
  - Solution: 3-layer fix (environment + code + batch file)
  - Result: 30-60x faster startup (20-40 seconds from cache)

================================================================================
QUICK START
================================================================================

Just double-click: START_SERVER.bat

The batch file will:
  1. Validate .env configuration
  2. Check model cache directory
  3. Clear Python __pycache__ (forces fresh imports)
  4. Stop existing Python processes
  5. Start the backend server

Expected output:
  - Model path with ALL backslashes (not mixed / and \)
  - "[SUCCESS] ✅ Hunyuan3D model FULLY LOADED and ready"
  - "Server running on http://127.0.0.1:5000"

First startup with cache: ~20-40 seconds
First startup without cache: ~15-30 minutes (downloads models)

================================================================================
WHAT WAS FIXED
================================================================================

1. ENVIRONMENT (.env file)
   - All paths now use Windows backslashes only
   - Added HY3DGEN_MODELS pointing to correct cache directory
   - No more mixed / and \ separators

2. SOURCE CODE (hy3dgen module)
   - shapegen/utils.py: Fixed path joining logic
   - texgen/pipelines.py: Fixed path joining logic
   - Normalizes forward slashes to backslashes

3. BACKEND STARTUP (main.py)
   - Loads .env BEFORE imports
   - Sets HOME and HY3DGEN_MODELS before hy3dgen module loads
   - (hy3dgen reads these at module import time, not at runtime)

4. BATCH FILE (START_SERVER.bat)
   - Validates .env exists
   - Clears Python cache to ensure fresh imports
   - Kills old Python processes
   - Better error messages

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Still seeing mixed path separators
  SOLUTION: Verify .env has HY3DGEN_MODELS line (not commented out)
            Run START_SERVER.bat again
            Check hy3dgen source files have the fix

PROBLEM: Slow startup (15-30 minutes)
  SOLUTION: Normal on first run (models downloading)
            Subsequent runs should be 20-40 seconds
            Check cache directory exists

PROBLEM: Python hangs
  SOLUTION: START_SERVER.bat automatically kills old processes
            Manual: taskkill /F /IM python.exe

PROBLEM: Can't find .env file
  SOLUTION: It's in the project root (C:\Users\johng\Documents\oscar\.env)
            START_SERVER.bat will create basic .env if missing
