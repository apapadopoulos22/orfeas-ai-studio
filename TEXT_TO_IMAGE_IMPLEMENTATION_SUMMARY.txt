HOW IT WORKS
================================================================================

Flow:
User enters prompt
    ↓
User adjusts parameters (steps, guidance, size)
    ↓
User clicks "Generate Image from Text"
    ↓
Frontend validates prompt
    ↓
Sends POST request to /api/text-to-image
    ↓
Backend connects to Ollama
    ↓
Ollama generates image using Stable Diffusion
    ↓
Backend returns base64-encoded PNG
    ↓
Frontend decodes and loads image
    ↓
Image displays on canvas
    ↓
All editing tools become available
    ↓
User can crop, filter, resize, export, etc.

API Request:
POST /api/text-to-image
Content-Type: application/json

{
  "prompt": "A red apple on a wooden table",
  "steps": 50,
  "guidance_scale": 7.5,
  "height": 768,
  "width": 768,
  "num_inference_steps": 50
}

API Response:
{
  "success": true,
  "image_base64": "iVBORw0KGgo...",
  "generation_time": 240,
  "model": "stable-diffusion"
}

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Generation failed - Make sure local LLM is running"
Solution:
1. Open terminal
2. Run: ollama serve
3. Wait for startup
4. Try generating again

Problem: "No image data in response"
Solution:
1. Check Ollama is running
2. Verify model: ollama list
3. Try smaller size first
4. Restart Ollama if stuck

Problem: "Very slow generation"
Solution:
1. Reduce steps (try 30 instead of 50)
2. Use 512×512 instead of 1024×1024
3. Check GPU is being used (monitor GPU usage)
4. Close other GPU applications

Problem: "Out of memory"
Solution:
1. Use smaller output size (512×512)
2. Reduce steps to 30
3. Close other programs
4. Restart system if needed

Problem: Generated image not showing
Solution:
1. Refresh the page
2. Try generating again with smaller settings
3. Check browser console for errors
4. Try different size/steps
