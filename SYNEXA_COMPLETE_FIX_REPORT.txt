  TROUBLESHOOTING
================================================================================

If You Still See CORS Errors:

1. Clear Browser Cache:
   - Chrome: Ctrl+Shift+Delete → Clear browsing data
   - Firefox: Ctrl+Shift+Delete → Clear Recent History
   - Edge: Ctrl+Shift+Delete → Choose what to clear

2. Verify Backend is Running:
   - Command: netstat -ano | findstr :5000
   - Should show: TCP 0.0.0.0:5000 LISTENING
   - Fix: cd backend && python main.py

3. Check API Base URL:
   - Open browser console (F12)
   - Type: console.log(API_BASE)
   - Should show: http://127.0.0.1:5000

4. Verify CORS Headers:
   - Open browser F12 → Network tab
   - Make a request to http://127.0.0.1:5000/api/health
   - Check Response Headers for: Access-Control-Allow-Origin: *

5. Restart Everything:
   - Kill backend: taskkill /F /IM python.exe
   - Clear browser cache (step 1)
   - Reload backend: cd backend && python main.py
   - Refresh browser (Ctrl+F5 hard refresh)
