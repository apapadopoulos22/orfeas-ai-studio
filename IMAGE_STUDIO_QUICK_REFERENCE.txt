## Figurine Enhance Guide

### What It Does
Extracts single element with B&W (Black & White) conversion

### When to Use
- Isolate objects from backgrounds
- Prepare for 3D model generation
- Enhance detail visibility
- High-contrast extraction

### How to Use
1. Upload image of object/figurine
2. Open "Figurine Enhance" section
3. Adjust Threshold slider (0-255)
   - Lower = More white areas
   - Higher = More black areas
4. Find optimal threshold visually
5. Click "Generate Figurine (BW PNG)"
6. Download as PNG
7. Use for 3D Studio

### Threshold Tips
| Threshold | Result |
|-----------|--------|
| 0-50 | Very light (mostly white) |
| 50-100 | Light grayscale |
| 100-150 | Medium balance |
| 150-200 | Dark emphasis |
| 200-255 | Very dark (mostly black) |

## Performance Tips

### For Speed
- Resize to 1000px width first
- Use JPG format (compression)
- Quality 70-80% for balance

### For Quality
- Use PNG format (lossless)
- Quality 90-100%
- Upload original size if possible

### For Size
- Use WebP format (best compression)
- Lower quality (60-70%)
- Resize to target dimensions

---

## Troubleshooting

### Issue: Image not loading
**Solution:** Check format (JPG, PNG, WebP) and try smaller file

### Issue: Filters not visible
**Solution:** Ensure image is loaded; try resetting filters

### Issue: Figurine enhance not working
**Solution:** Adjust threshold slider more; try different range

### Issue: Downloaded file too large
**Solution:** Use JPG format, lower quality, or resize smaller

### Issue: Export button not working
**Solution:** Load image first; check browser console (F12)
