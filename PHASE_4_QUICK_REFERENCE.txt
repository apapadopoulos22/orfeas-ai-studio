═══════════════════════════════════════════════════════════════════════════════
API ENDPOINTS REFERENCE
═══════════════════════════════════════════════════════════════════════════════

ROOT ENDPOINT
─────────────
GET /
  Returns API documentation
  Response: {name, phase, version, status, endpoints{}}

HEALTH ENDPOINTS
────────────────
GET /api/health
  Returns system health status
  Response: {status: "healthy", phase: "4", version: "1.0.0", timestamp}

GET /api/ready
  Returns readiness status
  Response: {ready: boolean, disciplines_loaded: number, version}

DISCIPLINE ENDPOINTS
────────────────────
GET /api/disciplines?limit=50&offset=0
  List all 403 disciplines with pagination
  Query Params: limit (1-500), offset (default 0), tier (1-12), category
  Response: {success: true, data: {disciplines[], count}, meta{}}

GET /api/disciplines/{id}
  Get single discipline details
  Path Params: id = discipline name/ID
  Response: {success: true, data: {name, category, tier, keywords, ...}}

GET /api/disciplines/{id}/related?max_results=50
  Get semantically related disciplines
  Path Params: id = discipline name
  Query Params: max_results (default 50)
  Response: {success: true, data: {discipline, related[], count}}

KNOWLEDGE GRAPH ENDPOINTS
──────────────────────────
GET /api/knowledge-graph?include_stats=true
  Get complete knowledge graph (403 nodes, 64 edges)
  Query Params: include_stats (true/false)
  Response: {success: true, data: {nodes[], edges[], statistics, graph_metrics}}

GET /api/disciplines/path/{from}/{to}?max_depth=5
  Find shortest path between disciplines (BFS)
  Path Params: from, to (discipline names)
  Query Params: max_depth (default 5)
  Response: {success: true, data: {from, to, path[], path_length, found}}

TIER & STATISTICS ENDPOINTS
────────────────────────────
GET /api/tier/{tier}/connections
  Get cross-tier connections analysis for tier 1-12
  Path Params: tier (1-12)
  Response: {success: true, data: {tier, disciplines, connections, ...}}

GET /api/statistics/phase3
  Get comprehensive Phase 3 system statistics
  Response: {success: true, data: {phase, total_disciplines, total_items, ...}}

ADVANCED QUERY ENDPOINT
───────────────────────
POST /api/query
  Advanced semantic query interface
  Body JSON:
    {
      "query_type": "semantic_search|related|pathfinding|tier_analysis",
      "params": { ... query-type-specific params ... }
    }

  Query Types:
    1. semantic_search
       params: {query: string, limit: number}

    2. related
       params: {discipline: string, max_results: number}

    3. pathfinding
       params: {from: string, to: string, max_depth: number}

    4. tier_analysis
       params: {tier: number}

ERROR RESPONSE FORMAT:
  {
    "success": false,
    "error": "Error Type",
    "message": "Detailed error message",

    "timestamp": "2025-10-28T15:20:30.123456"
  }

COMMON ERRORS:

400 Bad Request
  - Validation error (invalid parameters)
  - Example: max_depth out of range, limit > 500

404 Not Found
  - Discipline not found
  - Endpoint doesn't exist
  - Example: GET /api/disciplines/NONEXISTENT

405 Method Not Allowed
  - Wrong HTTP method for endpoint
  - Example: DELETE /api/disciplines (should be GET)

500 Internal Server Error
  - Unexpected server error
  - Check server logs for details

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Server won't start
SOLUTION:
  - Check port 5000 is available: netstat -ano | findstr :5000
  - Kill process using port: taskkill /PID <PID> /F
  - Try different port: Change line in phase4_app.py

ISSUE: Tests fail with import error
SOLUTION:
  - Ensure backend path is in sys.path (already in code)
  - Check Python 3.10+ installed
  - Install Flask: pip install flask flask-cors

ISSUE: Knowledge graph empty
SOLUTION:
  - Check Phase 3 mapper initialized correctly
  - Verify 403 disciplines loaded: GET /api/ready
  - Check server logs for errors

ISSUE: Slow response times
SOLUTION:
  - Without cache: Normal for first calls (~200ms)
  - Check if graph generation bottleneck: GET /api/knowledge-graph timing
  - Implement Redis cache for speedup
  - Consider query optimization
