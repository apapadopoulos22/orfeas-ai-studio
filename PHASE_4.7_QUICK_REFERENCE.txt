═══════════════════════════════════════════════════════════════════════════════
METRICS REFERENCE
═══════════════════════════════════════════════════════════════════════════════

HTTP METRICS:
  • http_requests_total - Total requests per endpoint
  • http_errors_total - Errors by status code
  • http_requests_in_progress - Current load
  • Request latency percentiles (p50, p95, p99)

CACHE METRICS:
  • cache_hits_total - Successful cache lookups
  • cache_misses_total - Cache misses
  • cache_hit_rate_percent - Hit rate (0-100%)
  • cache_size_bytes - Current cache size

AUTH METRICS:
  • auth_successes_total - Successful authentications
  • auth_failures_total - Failed authentication attempts
  • auth_success_rate_percent - Success rate (0-100%)

RATE LIMITING:
  • rate_limit_violations_total - Quota exceeded count

SECURITY:
  • sql_injection_attempts_total - SQL injection attempts
  • xss_attempts_total - XSS attack attempts

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Port 8000 already in use
  SOLUTION: Kill process: netstat -ano | grep 8000
            then: taskkill /PID <pid> /F

ISSUE: Module not found errors
  SOLUTION: pip install flask psutil

ISSUE: Health check returns degraded
  SOLUTION: Check individual components:
    curl http://localhost:8000/api/health/system
    curl http://localhost:8000/api/health/dependencies

ISSUE: Metrics all zeros
  SOLUTION: Make requests to main API (port 5000) to generate traffic
    curl http://localhost:5000/api/disciplines

ISSUE: Redis connection failed
  SOLUTION: Redis is optional. System uses in-memory cache as fallback.
            To use Redis: redis-server, then check:
            curl http://localhost:8000/api/health/dependencies

ISSUE: Cannot read log file
  SOLUTION: Check permissions: ls -la logs/
            Ensure logs/ directory exists: mkdir -p logs

ISSUE: Tests won't run
  SOLUTION: cd backend && python test_phase4_monitoring.py
            If import errors: pip install -r requirements.txt

KEY METRICS FORMULAS
═══════════════════════════════════════════════════════════════════════════════

Cache Hit Rate:
  = (cache_hits / (cache_hits + cache_misses)) * 100

Auth Success Rate:
  = (auth_successes / (auth_successes + auth_failures)) * 100

Error Rate:
  = (http_errors / http_requests) * 100

Throughput (requests/min):
  = http_requests / uptime_minutes

Avg Latency:
  = sum(request_latencies) / request_count

Security Event Rate:
  = (sql_injection_attempts + xss_attempts) / time_period

GLOSSARY
═══════════════════════════════════════════════════════════════════════════════

COUNTER: Monotonically increasing metric (never decreases)
GAUGE: Metric that can increase or decrease
HISTOGRAM: Distribution of values (latencies, sizes)
PERCENTILE: Value below which percentage of data falls
LATENCY: Time taken to respond to request
THROUGHPUT: Requests processed per unit time
SLA: Service Level Agreement (performance targets)
