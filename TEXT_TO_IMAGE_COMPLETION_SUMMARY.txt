HOW TO USE

════════════════════════════════════════════════════════════════════════════════

REQUIREMENT: Ollama must be running
  Terminal: ollama serve

STEP 1: ENTER PROMPT
  • Click in the textarea
  • Type description: "A red apple on a wooden table"
  • Be specific and detailed

STEP 2: ADJUST PARAMETERS (optional)
  • Steps: 50 (balanced, 3-5 minutes)
  • Guidance: 7.5 (balanced accuracy/creativity)
  • Size: 768×768 (recommended quality)

STEP 3: CLICK GENERATE
  • Click "✨ Generate Image from Text"
  • Wait for progress bar to complete (typically 3-5 minutes)
  • Image appears on canvas

STEP 4: EDIT & EXPORT
  • Use any of the 7 editing tools
  • Compare before/after
  • Export in PNG/JPG/WebP

TROUBLESHOOTING

════════════════════════════════════════════════════════════════════════════════

ISSUE: "Generation failed - Make sure local LLM is running"
  → Open terminal, run: ollama serve
  → Wait for startup, try again

ISSUE: Very slow generation
  → Reduce steps to 30-40
  → Use 512×512 instead of 1024×1024
  → Close other GPU applications

ISSUE: "Out of memory"
  → Use smaller size (512×512)
  → Reduce steps to 30
  → Restart Ollama

ISSUE: Generated image not showing
  → Refresh browser
  → Try again with smaller settings
  → Check browser console (F12)
