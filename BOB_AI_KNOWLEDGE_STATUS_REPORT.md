## Troubleshooting

### Issue: Knowledge not being applied

**Solution:** Ensure `BOB_AI_KB_AVAILABLE=True` in LLM module

### Issue: Slow performance

**Solution:** v7.0 uses caching - first query slower, subsequent queries fast

### Issue: Missing domain

**Solution:** Check domain keywords - may need custom enhancement

### Issue: Import errors

**Solution:** Verify backend path in Python sys.path
