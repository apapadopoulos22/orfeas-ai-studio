WHAT YOU SEE
================================================================================

1. BEFORE (Left Side) - 📸 Original
   • Shows your original uploaded image
   • Dimensions displayed below
   • Updated when you upload a new image
   • Never changes during editing

2. AFTER (Right Side) - ✨ Generated
   • Shows your current edited image
   • Updates in real-time as you edit
   • Displays current dimensions
   • Reflects all applied changes

3. STATISTICS (Bottom)
   • Compression: Shows file size change
     Example: "-5.2%" (smaller) or "+2.1%" (larger)

   • Dimensions: Shows size change
     Example: "-100×50" (cropped) or "+200×0" (wider)

   • Mods: Shows number of edits
     Example: "2 operations" (2 edits applied)

TYPICAL USER WORKFLOW
================================================================================

STEP 1: UPLOAD
┌─ Drag and drop image or click upload
└─→ Comparison panel appears automatically
    ├─ Before shows your original
    ├─ After shows "No result yet"
    └─ Ready for editing

STEP 2: CROP
┌─ Select crop aspect ratio
├─ Click "Apply Crop"
└─→ Comparison panel updates
    ├─ After image shows cropped version
    ├─ Dimensions change displayed

    └─ Mods shows "1 operation"

STEP 3: APPLY FILTERS
┌─ Adjust filter sliders (brightness, contrast, etc.)
└─→ Comparison updates in real-time
    ├─ After image shows filtered version
    ├─ Stats recalculate
    └─ Mods shows "2 operations"

STEP 4: RESIZE
┌─ Enter new width and height
├─ Click "Apply Resize"
└─→ Comparison panel updates
    ├─ After image rescaled
    ├─ Dimension change shows new delta
    └─ Mods shows "3 operations"

STEP 5: VIEW COMPARISON
┌─ Side-by-side before/after visible
├─ Statistics show cumulative changes
└─ Professional feedback on edits

STEP 6: EXPORT
┌─ Choose format (PNG, JPG, WebP)
├─ Set quality
├─ Click "Download"
└─→ Edited image (after) downloaded
    Original (before) remains unchanged

COMMON QUESTIONS
================================================================================

Q: Why is "After" empty when I first upload?
A: It shows "No result yet" because you haven't applied any edits.
   After you crop, filter, or resize, it will show your edited image.

Q: Does the original image change?
A: No! The original (Before) never changes. Only the edited (After)
   updates as you apply edits. When you export, only the edited
   version is downloaded.

Q: Why do dimensions show 0×0 initially?
A: That's the dimension CHANGE (delta). When you first upload,
   there's no change yet. After cropping or resizing, it shows
   how much the dimensions changed.

Q: What does compression mean?
A: It's the file size change percentage. "-5.2%" means the file
   is 5.2% smaller after edits. "+2.1%" means it's 2.1% larger.

Q: How does the operation counter work?
A: It shows total edits applied. Each time you crop, filter,
   resize, apply color, or enhance figurine, it increments by 1.
   Useful to see how many changes you've made.

Q: Can I undo changes?
A: Currently, you can reset by uploading a new image. Or manually
   undo each edit using the tool reset buttons (Reset Crop, etc.).
   Full undo/redo may be added in future updates.

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Comparison panel not showing
SOLUTION: Upload an image first. Panel appears after upload.

PROBLEM: Before and After images look the same
SOLUTION: Check Mods count. If it says "None yet", apply an edit first.

PROBLEM: Dimensions show strange numbers
SOLUTION: This is the CHANGE (delta), not absolute size.
          Use the dimension displays under each image for absolute size.

PROBLEM: Stats not updating
SOLUTION: Make sure you're clicking "Apply" buttons, not just adjusting sliders.
          Click the action button to trigger the update.

PROBLEM: After image is blurry
SOLUTION: If you've zoomed way in, the canvas display may compress.
          This is just the preview - export quality is controlled by format/quality.
