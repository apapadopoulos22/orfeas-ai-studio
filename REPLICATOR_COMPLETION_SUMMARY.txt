TECHNOLOGY STACK
════════════════════════════════════════════════════════════════════════════════

Backend:
  • Python 3.11 with Flask
  • OpenCV (cv2) for computer vision
  • PyTorch + CUDA for GPU acceleration (RTX 3090)
  • NumPy for numerical operations

Frontend:
  • HTML5 with CSS3
  • Vanilla JavaScript
  • Drag-drop file API
  • Fetch API for backend communication

API:
  • RESTful architecture
  • JSON request/response
  • Multipart form data
  • CORS enabled

FEATURE SPECIFICATIONS
════════════════════════════════════════════════════════════════════════════════

INPUT:
  • Formats: PNG, JPG, WebP
  • Resolution: 3+ megapixels
  • Size: <50MB per image

PROCESSING:

OUTPUT:
  • 3D Models: OBJ format (GLB compatible)
  • Reports: HTML with full analysis
  • Data: JSON with all measurements
