================================================================================
                           TROUBLESHOOTING FLOWCHART
================================================================================

Issue: Frontend not loading
  → Check Vercel dashboard
  → Verify build was successful
  → Clear browser cache
  → Try incognito mode
  → Check network tab for 404s

Issue: Backend returning errors
  → Check Heroku logs: heroku logs --tail
  → Verify environment variables set
  → Check free tier dyno is running
  → Restart dyno: heroku restart
  → Check backend local version first

Issue: CORS errors between frontend and backend
  → Verify backend CORS_ORIGINS configured
  → Check frontend is making requests to correct URL
  → Verify frontend URL matches CORS_ORIGINS
  → Check browser console for exact error
  → Temporarily disable CORS for testing

Issue: Slow response times
  → Check Heroku dyno size (may need paid plan)
  → First request loads model (~50s expected)
  → Verify not many concurrent users
  → Check Vercel CDN is being used
  → Review slow queries in logs

Issue: Out of memory errors
  → Heroku free tier limited to 512MB
  → May need to upgrade dyno
  → Consider AWS for larger memory
  → Optimize model loading
  → Reduce batch sizes

Solution path:
  Problem ──→ Check logs ──→ Verify config ──→ Test locally ──→ Deploy fix ──→ Verify
