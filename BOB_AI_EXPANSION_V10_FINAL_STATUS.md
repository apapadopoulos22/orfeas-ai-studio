## API Usage Examples

### Get Total Statistics

```python
    TOTAL_NEW_DISCIPLINES,
    TOTAL_KNOWLEDGE_ITEMS
)

print(f"Disciplines: {TOTAL_NEW_DISCIPLINES}")      # 391
print(f"Knowledge Items: {TOTAL_KNOWLEDGE_ITEMS}")  # 51,672
```

### List All Disciplines

```python
from backend.bob_ai_expansion_200_disciplines import get_all_new_disciplines

all_disciplines = get_all_new_disciplines()
for name, info in list(all_disciplines.items())[:5]:
    print(f"{name}: {info['items']} items")
```

### Get Tier-Specific Disciplines

```python
from backend.bob_ai_expansion_200_disciplines import get_disciplines_by_tier

tier5 = get_disciplines_by_tier(5)
print(f"Tier 5 has {len(tier5)} disciplines")  # 41

for discipline, info in tier5.items():
    print(f"  • {discipline} ({info['items']} items)")
```

### Access Tier Class Directly

```python
from backend.bob_ai_expansion_200_disciplines import Tier9TechnologyEngineering

tech_disciplines = Tier9TechnologyEngineering.DISCIPLINES
ml_info = tech_disciplines.get("Machine Learning")
print(f"Machine Learning: {ml_info['items']} items")
print(f"Keywords: {', '.join(ml_info['keywords'])}")
```
