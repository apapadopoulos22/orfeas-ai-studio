TECHNICAL SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

CACHING SYSTEM
──────────────
Architecture: Two-tier (Redis primary, in-memory fallback)
TTL Range: 1 second to unlimited
Default TTL: 300 seconds (5 minutes)
Max Cache Size: 100MB (in-memory), unlimited (Redis)
Hit Rate Target: 70-80% for frequently accessed data
Performance: <1ms average cache lookup time

Cache Decorator:
  @CacheManager.cache_response(ttl=300, key_prefix="api")
  def expensive_function():
      # Automatically cached

AUTHENTICATION SYSTEM
──────────────────────
Key Format: bob_ai_{32-byte-random}
Key Storage: SHA256 hashes (never plain text)
Default Scopes: read:disciplines, read:graph, read:statistics
Admin Scopes: admin:*, write:* (full access)
Expiration: Configurable per key (optional)
Default Keys: Development (unrestricted), Read-Only (100 req/min)

Decorator Usage:
  @app.route('/api/protected')
  @require_api_key
  def protected_endpoint():
      # API key required
      api_key_id = request.api_key_id
      api_key_data = request.api_key_data
      return jsonify({"authenticated": True})

RATE LIMITING
──────────────
Algorithm: Token Bucket (fixed-window equivalent)
Default Limit: 100 requests/minute
Minimum Limit: 1 request/minute
Maximum Limit: Unlimited (for special keys)
Token Refill: Continuous (smooth, no bursts)
Tracking: Per-API-key or per-IP-address
Response Headers: X-RateLimit-* headers included

Decorator Usage:
  @check_rate_limit
  def api_endpoint():
      # Automatic rate limit checking

INPUT VALIDATION
─────────────────
SQL Injection Prevention:
  - Keywords: SELECT, INSERT, UPDATE, DELETE, DROP, UNION, etc.
  - Operators: =, ;, --, /*, */
  - Procedures: xp_, sp_, exec, execute

XSS Prevention:
  - HTML tags: <script>, <iframe>, <object>
  - Event handlers: onerror, onclick
  - JavaScript: javascript:, eval(), expression()

Type Validation:
  - Discipline IDs: [a-zA-Z0-9\s\-_\.&\'()]+ max 100 chars
  - Search Queries: [a-zA-Z0-9\s\-_\.&\'(),;:?!]+ max 200 chars
  - Tier Numbers: 1-12 (integer only)
  - Pagination: limit (1-100), offset (0+)

SECURITY HEADERS
─────────────────
Automatically Added to All Responses:

  X-Content-Type-Options: nosniff
    → Prevent MIME-type sniffing

  X-Frame-Options: DENY
    → Prevent clickjacking

  X-XSS-Protection: 1; mode=block
    → Enable XSS filter in browsers

  Strict-Transport-Security: max-age=31536000; includeSubDomains
    → Force HTTPS for 1 year

  Content-Security-Policy: default-src 'self'; script-src 'self'
    → Restrict resource loading

Rate Limit Headers (When Applicable):

  X-RateLimit-Limit: 100
    → Maximum requests allowed

  X-RateLimit-Remaining: 45
    → Requests remaining in current window

  X-RateLimit-Reset: 1730131400
    → Unix timestamp when limit resets

  Retry-After: 60 (on 429 responses)
    → Seconds until retry allowed
