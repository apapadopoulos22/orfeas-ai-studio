FEATURE SPECIFICATIONS
────────────────────────────────────────────────────────────────────────────────

INPUT:
  • Format: PNG, JPG, WebP
  • Resolution: 3+ megapixels recommended
  • Size: <50MB per image
  • Count: 2-8 images per analysis

RULER DETECTION:
  • Auto-detection: Yes (Canny edge + contour analysis)
  • Types supported: cm rulers, inch rulers, metric scales, reference objects
  • Calibration: Automatic pixel-to-mm ratio calculation
  • Manual override: Yes (user can specify custom calibration)
  • Accuracy: Depends on ruler visibility and perpendicularity

DIMENSION EXTRACTION:
  • Measurements: Width, Height, Depth
  • Units: Millimeters (with ruler reference)
  • Accuracy with ruler: ±2-5%
  • Accuracy without ruler: ±10-20%
  • Confidence scoring: 0-100% for each dimension

GEOMETRY CLASSIFICATION:
  • Types: Box, Cylinder, Sphere, Irregular, Assembly
  • Method: Contour analysis using circularity and eccentricity metrics
  • Feature extraction: Automatically identifies shape characteristics
  • Assembly detection: Supports multi-part objects

CAVITY DETECTION:
  • Method: Edge sharpness analysis + morphological operations
  • Output: Cavity locations and confidence scores
  • Photo suggestions: Recommended angles to capture cavities
  • Macro shots: Suggested for detailed coverage

BATCH PROCESSING:
  • Multi-image handling: Processes all images in parallel/sequential
  • Statistics aggregation: Averages confidence across images
  • Session management: Unique session ID per analysis
  • Result combination: Combines measurements with confidence scoring

OUTPUT:
  • 3D Model: OBJ format mesh (can be imported to CAD/3D printing software)
  • Report: HTML with analysis data, dimensions, suggestions
  • Metadata: Analysis timestamp, session ID, image count, confidence scores
