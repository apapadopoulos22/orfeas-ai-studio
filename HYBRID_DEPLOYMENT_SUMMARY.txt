================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot connect to backend"
SOLUTION:
  1. Check backend running: netstat -ano | findstr :5000
  2. Check health: curl http://localhost:5000/health
  3. Check browser console for CORS errors (F12)
  4. Verify backend URL in HTML matches (localhost:5000)
  5. Restart backend: Stop and run again


PROBLEM: CORS Error in Console
SOLUTION:
  1. Ensure backend has CORS enabled
  2. Check frontend URL in CORS whitelist
  3. Restart backend
  4. Hard refresh browser (Ctrl+F5)


PROBLEM: WebSocket Connection Failed
SOLUTION:
  1. Backend must support WebSocket
  2. Check WS_URL configuration
  3. Verify firewall not blocking
  4. Check port 5000 is open locally


PROBLEM: Frontend loads but no data
SOLUTION:
  1. Check browser Network tab (F12)
  2. Look for failed API calls
  3. Verify BACKEND_URL is correct
  4. Check backend terminal for errors
  5. Test backend directly: curl http://localhost:5000/api/knowledge/search


PROBLEM: Port 5000 Already in Use
SOLUTION:
  # Find process using port 5000
  netstat -ano | findstr :5000

  # Kill process (replace PID)
  taskkill /F /PID 1234

  # Restart backend
  python main.py
