### LLM Integration Pipeline
```
User Input
    ↓
[Keyword Detection] → Identifies relevant domains
    ↓
[Multi-Domain Enrichment] → Applies knowledge from detected domains
    ↓
[Prompt Enhancement] → Returns enriched prompt + metadata
    ↓
[System Prompt Injection] → Adds domain context to system prompt
    ↓
[LLM Processing] → Sends to Ollama/Mistral with enhanced context
    ↓
Enhanced Response
```
