TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Server won't start?
  → Check logs: backend/logs/backend_requests.log
  → Run validation: python validate_model_cache.py

Models still downloading?
  → Re-run: python setup_model_cache.py
  → Or restart with: .\start_backend.ps1 (shows more details)

Port 5000 already in use?
  → Find process: netstat -ano | findstr :5000
  → Kill it: taskkill /F /PID <PID>
