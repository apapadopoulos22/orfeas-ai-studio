INTEGRATION (10 minutes)
========================

Add this code to main.py AFTER Phase 1 initialization (around line 170):

```python
# [BOB AI EXPANSION] Initialize Phase 2
try:
    from bob_ai_expansion_phase2_knowledge_graph import initialize_knowledge_graph
    from bob_ai_expansion_phase2_search import AdvancedSearchEngine
    from bob_ai_expansion_phase2_api import init_bob_ai_phase2_api

    db_session = expansion_loader.Session()
    graph, analyzer, recommendation_engine = initialize_knowledge_graph(db_session)

    if graph:
        search_engine = AdvancedSearchEngine(expansion_loader.Session(), use_elasticsearch=False)
        init_bob_ai_phase2_api(app, expansion_loader.Session, analyzer, recommendation_engine, search_engine)
        logger.info("✅ BOB AI Phase 2 initialized")
except Exception as e:
    logger.warning(f"Phase 2 error: {e}")
```

Run: python main.py


NEW CAPABILITIES (10+ endpoints)
===============================

Knowledge Graph Analysis:
  GET /api/v2/graph/analyze/42
  → Returns: prerequisites, related topics, network importance

Recommendations:
  GET /api/v2/recommendations?completed=1,2,3
  → Returns: what to study next based on completed disciplines

Learning Paths:
  GET /api/v2/learning-paths/optimized/42
  → Returns: optimal path to reach discipline 42

Skill Gap Analysis:
  POST /api/v2/skill-gaps/analyze/42
  → Body: {"skills": ["Python", "Statistics"]}
  → Returns: missing skills, how to fill gaps

Advanced Search:
  POST /api/v2/search/advanced
  → Body: {"query": "machine learning", "filters": {...}}
  → Returns: search results with facets

Skill Search:
  GET /api/v2/search/by-skill?skills=Python,Data%20Science

Industry Search:
  GET /api/v2/search/by-industry?industry=Finance
