## Human Forms

### Anatomy Terms

- **Head/Face**: face, head, facial, expression, emotion
- **Body**: body, torso, posture, stature, frame
- **Limbs**: arm, hand, leg, foot
- **Features**: eye, nose, mouth, ear, hair

### Physical Descriptors

- **Build**: muscular, lean, robust, athletic, slender, strong
- **Movement**: agile, graceful, powerful, flexible, rigid
- **Presence**: fierce, gentle, intense, peaceful, noble

### Example Prompts

```
✓ "a muscular warrior with intense gaze and flowing hair"
✓ "a graceful dancer with elegant posture and delicate features"
✓ "a powerful human with athletic build and confident stance"
✓ "a wise elder with peaceful expression and kind eyes"
```

## Hybrid & Blended Forms

### Anthropomorphic (Animal + Human Intelligence/Behavior)

When describing anthropomorphic creatures, use both animal and human descriptors:

```
✓ "an anthropomorphic lion standing upright with intelligent eyes"
✓ "an anthropomorphic fox in ranger outfit with bow"
✓ "an anthropomorphic bear with blacksmith hammer and leather apron"
✓ "an anthropomorphic crow in wizard robes with magical staff"
```

### Mixed Creature Features

Combine different animal characteristics:

```
✓ "a chimera with eagle wings, lion body, and serpent tail"
✓ "a griffin combining eagle head with lion body"
✓ "a basilisk with scales, serpent fangs, and hypnotic eyes"
✓ "a dragon with reptile scales, bird wings, and mammalian features"
```

## Spell Check Tips

- **Verify Anatomy**: "musclar" → "muscular", "humman" → "human"
- **Animal Names**: "dinasaur" → "dinosaur", "elve" → "elf"
- **Body Parts**: "figrue" → "figure", "expresion" → "expression"
- **Qualities**: "powerfull" → "powerful", "gracefull" → "graceful"
