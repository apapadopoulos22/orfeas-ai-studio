TROUBLESHOOTING
===============

Issue: Backend won't start
Solution: Check port 5000 is not in use
  netstat -ano | findstr :5000
  If in use: taskkill /F /IM python.exe

Issue: CORS errors in browser
Solution: Verify CORS headers in response
  Check CORS_TEST_FRONTEND.html for debugging
  Ensure browser allows access from file:// origin

Issue: GPU out of memory
Solution: Reduce in .env
  GPU_MEMORY_LIMIT=0.75
  MAX_CONCURRENT_JOBS=2

Issue: Slow response times
Solution: Check GPU and CPU usage
  nvidia-smi (GPU stats)
  tasklist (CPU usage)
  Check for other processes competing for resources
