## 🚀 GETTING STARTED

### Step 1: Review Documentation

```
Start with: BOB_AI_EXPANSION_100_CATEGORIES_500_DISCIPLINES.md
Then read: BOB_AI_EXPANSION_IMPLEMENTATION_GUIDE.md
Reference: BOB_AI_LIBRARY_ECOSYSTEM_AND_INTEGRATION.md
```

### Step 2: Setup Environment

```
# Create database
createdb bob_ai_expanded

# Setup Python environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Step 3: Run Migrations

```
# Create tables
alembic upgrade head

# Load categories
python scripts/load_categories.py

# Load disciplines
python scripts/load_disciplines.py

# Map libraries
python scripts/load_libraries.py
```

### Step 4: Start Development

```
# Backend API
cd backend && python main.py

# Frontend development
cd frontend && npm run dev

# Run tests
pytest backend/tests -v
npm test
```
