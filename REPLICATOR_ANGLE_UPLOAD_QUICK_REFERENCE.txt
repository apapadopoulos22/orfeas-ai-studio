🎯 BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

Photography Tips:
  ✓ Good lighting (bright, even, no shadows)
  ✓ Steady camera (use tripod)
  ✓ Object centered in frame
  ✓ Include ruler for scale
  ✓ Capture full object from all angles

Angle Strategy:
  For Best Accuracy (All 8 angles):
    Use: Front + Right + Back + Left + Top + Bottom + Macro + Diagonal
    Time: ~45 seconds
    Accuracy: ±2-5% (with ruler)

  For Good Accuracy (4 angles):
    Use: Front + Right + Back + Left
    Time: ~15 seconds
    Accuracy: ±5-10% (with ruler)

  For Quick Scan (2 angles):
    Use: Front + Right
    Time: ~8 seconds
    Accuracy: ±15-20% (estimation)

📁 FILE REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

Format:           PNG, JPG, WebP
Size per image:   < 50MB
Resolution:       Min 1920x1440, Recommended 3840x2880
Total per slot:   1 image max
Total session:    Up to 8 images (one per slot)


⚡ ACCURACY LEVELS
═══════════════════════════════════════════════════════════════════════════════

With Ruler (Scale Calibration):
  ± 2-5%   ────  8 angles (complete coverage)
  ± 5-10%  ────  4 angles (standard coverage)
  ± 10-20% ────  2 angles (basic coverage)

Without Ruler (Estimation):
  ± 10-20% ────  8 angles
  ± 15-30% ────  4 angles
  ± 25-40% ────  2 angles

Note: Include ruler in at least one angle for best accuracy!

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: Photos not uploading
  → Check: File format (PNG, JPG, WebP)?
  → Check: File size < 50MB?
  → Try: Different browser
  → Try: File in regular upload area instead

Issue: Analysis won't start
  → Check: At least 1 photo uploaded?
  → Check: Ruler settings correct?
  → Try: Fewer angles first
  → Clear: Browser cache

Issue: Low accuracy
  → Add: Ruler for scale
  → Use: More angles (4+ instead of 2)
  → Check: Photo quality (bright, sharp)
  → Include: Ruler in multiple angles

Issue: Counter not updating
  → Refresh: Browser (Ctrl+F5)
  → Check: Browser console (F12) for errors
  → Try: Re-uploading photos

🚀 PRO TIPS
═══════════════════════════════════════════════════════════════════════════════

Tip 1: Organization
  Pre-name files like: "object_front.jpg", "object_right.jpg"
  Makes uploading faster and less confusing

Tip 2: Batch Analysis
  Upload multiple angle sets
  Analyze each separately
  Compare results for consistency

Tip 3: Quality Control
  Start with 4-angle upload
  Review results
  Re-shoot if needed
  Then use all 8 angles for final

Tip 4: Export Strategy
  OBJ: Universal, good for 3D apps
  STL: 3D printing, slicing software
  GLB: Web viewing, game engines
  Choose based on your use case

Tip 5: Archive Results
  Save all angle photos + exported model
  Keep ruler reference for future scaling
  Document actual measurements
  Makes it easy to re-analyze later
