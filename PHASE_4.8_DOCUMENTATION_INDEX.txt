TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Build fails:
  • Check Docker running: docker ps
  • Verify files: ls -la Dockerfile requirements.txt backend/
  • Check syntax: docker build --no-cache .

Port already in use:
  • Find process: lsof -i :5000
  • Kill: kill -9 <PID>
  • Or change port in docker-compose.yml

Container exits:
  • Check logs: docker-compose logs api
  • Verify health: curl http://localhost:5000/health

Volumes not mounting:
  • Check permissions: ls -la ./models ./outputs ./logs
  • Verify config: docker-compose config | grep volumes
  • Recreate: docker-compose down -v && docker-compose up -d
