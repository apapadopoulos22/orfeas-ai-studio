QUICK REFERENCE - COMMON COMMANDS
═══════════════════════════════════════════════════════════════════════════════

  cd backend && python -u main.py

Stop Backend:
  Ctrl+C in terminal

Health Check:

API Test:
  curl -X OPTIONS http://localhost:5000/api/replicator/analyze

Kill Port 5000:
  netstat -ano | findstr :5000  (find PID)
