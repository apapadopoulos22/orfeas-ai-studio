WHY THIS HAPPENS:
=================
When you edit Python files and commit them, the old Python process
keeps running the old code. The new code doesn't load until you
restart the Python process.

This is not a bug - it's how Python works. Code changes require
a process restart to take effect.

2. Did you commit and push?
3. Is there a .pyc cache file blocking the update?

If all else fails, try:

The -B flag prevents Python from using cached .pyc files.
