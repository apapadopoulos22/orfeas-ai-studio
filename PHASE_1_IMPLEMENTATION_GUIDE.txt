===============================================

Quick Start for Developers
==========================

This guide walks through implementing the BOB AI expansion (100 categories,
500 disciplines, 800+ libraries) into the existing ORFEAS platform.

NEXT STEPS
==========

Step 1: Install Dependencies (5 minutes)
-----------------------------------------

```bash
cd backend
pip install sqlalchemy alembic
```

Step 2: Generate Sample Data (2 minutes)
--------------------------------------

```bash
python bob_ai_expansion_data_loader.py --generate-sample-data
```

This creates:
  - data/categories.csv (100 categories)
  - data/categories.json
  - data/disciplines.csv (500 disciplines)
  - data/libraries.csv (800+ libraries)

Step 3: Create Database (2 minutes)
----------------------------------

Initialize SQLite database:

```bash
python -c "
from bob_ai_expansion_phase1_database import initialize_bob_ai_expansion
loader = initialize_bob_ai_expansion('sqlite:///./bob_ai.db')
print('✅ Database initialized')
"
```

Or with PostgreSQL:

```bash
python -c "
from bob_ai_expansion_phase1_database import initialize_bob_ai_expansion
loader = initialize_bob_ai_expansion('postgresql://user:pass@localhost/bob_ai')
print('✅ Database initialized')
"
```

Step 4: Load Data (5 minutes)
----------------------------

```bash
python bob_ai_expansion_data_loader.py \
  --load-database sqlite:///./bob_ai.db \
  --categories-file data/categories.csv \
  --disciplines-file data/disciplines.csv \
  --libraries-file data/libraries.csv
```

Output:
  ✅ Loaded 115 categories
  ✅ Loaded 891 disciplines
  ✅ Loaded 800+ libraries

Step 5: Integrate with main.py (10 minutes)
-----------------------------------------

In backend/main.py, add after Flask initialization:

```python
# Around line 100-150 in main.py

# [BOB AI EXPANSION] Initialize Phase 1 API
from bob_ai_expansion_phase1_api import init_bob_ai_expansion_api
from bob_ai_expansion_phase1_database import ExpandedKnowledgeLoader
from sqlalchemy.orm import sessionmaker

# Initialize database
database_url = os.getenv('BOB_AI_DATABASE_URL', 'sqlite:///./bob_ai.db')
expansion_loader = ExpandedKnowledgeLoader(database_url)
expansion_loader.connect()

# Get session factory
Session = expansion_loader.Session

# Register API endpoints
init_bob_ai_expansion_api(app, Session)

logger.info("✅ BOB AI Expansion Phase 1 initialized")
```

Step 6: Test API Endpoints (5 minutes)
--------------------------------------

Start the server:
```bash
python main.py
```

Test endpoints:

```bash

curl http://localhost:5000/api/v2/categories/expanded

```

Expected responses:

DATABASE SCHEMA DETAILS
======================

5 New Tables:

1. expanded_categories (115 rows)
   - id, name, tier (1-8), description
   - disciplines_count, libraries_count
   - keywords, maturity_level

2. expanded_disciplines (891 rows)
   - id, name, category_id, description
   - difficulty_level, estimated_hours
   - use_cases, topics, keywords
   - estimated_hours, certification_available

3. library_mappings (800+ rows)
   - id, discipline_id, library_name, package_name
   - language, version, install_command
   - documentation_url, github_url
   - relevance_score, technology_stack

4. discipline_links (relationships)
   - source_discipline_id, target_discipline_id
   - link_type (prerequisite, related, follow-up)
   - strength (0-1)

5. learning_paths (curated paths)
   - id, name, description
   - discipline_ids, library_ids
   - estimated_duration_weeks, skill_level
   - target_role, industry_focus


API ENDPOINTS (15+)
===================

GET /api/v2/categories/expanded
  Query: page, per_page, tier, maturity, search
  Response: {categories: [...], total: 115, page: 1}

GET /api/v2/categories/<id>
  Response: Full category with all disciplines

GET /api/v2/categories/<id>/disciplines
  Response: All disciplines in category

GET /api/v2/disciplines/expanded
  Query: page, per_page, category, difficulty, status, search
  Response: {disciplines: [...], total: 891}

GET /api/v2/disciplines/<id>
  Response: Full discipline with libraries and prerequisites

POST /api/v2/disciplines/search
  Body: {query, difficulty, category_id, limit}
  Response: {results: [...], count: N, query_time_ms: X}

GET /api/v2/libraries
  Query: page, per_page, discipline_id, language, technology_stack, search
  Response: {libraries: [...], total: 800+}

POST /api/v2/libraries/search
  Body: {query, language, technology_stack, limit}
  Response: {results: [...], count: N}

GET /api/v2/learning-paths
  Query: skill_level, industry, search
  Response: {paths: [...], total: N}

GET /api/v2/learning-paths/<id>
  Response: Full path with disciplines and libraries

GET /api/v2/statistics
  Response: {categories: 115, disciplines: 891, libraries: 800+, ...}

GET /api/v2/health
  Response: {status: healthy, service: "BOB AI Expansion v10.0"}

TROUBLESHOOTING
===============

Issue: "ModuleNotFoundError: No module named 'sqlalchemy'"
Solution: pip install sqlalchemy

Issue: Database connection error
Solution: Check database URL format and credentials
  SQLite: sqlite:///./bob_ai.db
  PostgreSQL: postgresql://user:pass@host:5432/dbname
  MySQL: mysql+pymysql://user:pass@host/dbname

Issue: No data showing up
Solution: Run data loader script
  python bob_ai_expansion_data_loader.py --load-database sqlite:///./bob_ai.db

Issue: API returns 500 error
Solution: Check logs for specific error, verify database connection
