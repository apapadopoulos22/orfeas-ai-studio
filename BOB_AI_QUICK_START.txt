## 🎯 Quick Start (5 Minutes)

### Step 1: Install Dependencies
```bash
cd backend
pip install svgwrite svgpathtools ollama
```

### Step 2: Start Ollama (if not running)
```bash
# Terminal 1
ollama serve
# Ensure mistral model exists: ollama pull mistral
```

### Step 3: Start Backend
```bash
# Terminal 2
cd backend
python main.py
# Wait for "setup_routes() COMPLETED"
```

### Step 4: Test Endpoints
```bash
# Terminal 3
python test_bob_ai_backend.py
# Should see all tests PASS
```

### Step 5: Use Frontend
```
Open: http://localhost:5000/studio
Scroll to: 2.5D Studio section
Try: "Bob AI Text to Vector" form
```

## 🎨 Features at a Glance

### Text-to-Vector Generation
- **Input**: Text prompt + style + complexity
- **Output**: Valid SVG with path count & download link
- **Styles**: geometric, organic, abstract, decorative, technical, artistic
- **Complexity**: simple (10-50 paths), medium (50-150), complex (150-300+)

### Vector Enhancement
- **Simplify**: Reduce paths for faster cutting
- **Complexify**: Add detail and complexity
- **Stylize**: Apply artistic styling
- **Custom**: User-specified modifications

## 🚨 Troubleshooting

### "Ollama manager not available"
**Solution**: Start Ollama (`ollama serve`) - system will use fallback generation

### "Invalid style" error
**Solution**: Use one of: geometric, organic, abstract, decorative, technical, artistic

### "Invalid complexity" error
**Solution**: Use one of: simple, medium, complex

### Slow generation
**Solution**: Use "simple" complexity or wait (first run may be slower)
