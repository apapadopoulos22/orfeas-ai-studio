## 🎬 VIDEO RECORDING TIPS (2 MIN READ)

### Best Practices

```
✅ DO:
├─ Smooth camera motion (use tripod/gimbal)
├─ Bright, even lighting
├─ Include ruler for scale
├─ 360° panning around object
├─ Steady 30-60 FPS frame rate
└─ 10-60 second duration

❌ DON'T:
├─ Jerky/shaky camera movement
├─ Dark or heavily shadowed video
├─ Backlit subjects
├─ Transparent or reflective objects only
├─ Very fast or very slow motion
└─ Over 500MB file size
```

### Recording Example

```
Phone/Camera Setup:
1. Place object on flat surface
2. Position camera at eye level
3. Start recording
4. Slowly pan around object (10-20 seconds)
5. Stop recording

Time-Lapse Setup:
1. Position camera fixed above object
2. Use 360° rotating turntable (optional)
3. Record 30-60 seconds of rotation
4. Video captures all angles
```

## 📝 UNDERSTANDING CAPTIONS

### Caption Format

```
"Object fills frame | Colors: blue, neutral | Sharp edges | Angle: direct_view"

Components:
├─ Object size: "Object fills frame", "Object clearly visible", "Object in frame"
├─ Colors: Red, Orange/Yellow, Green, Cyan, Blue, Magenta, Dark, Bright, Neutral
├─ Surface: Texture info if detected
├─ Shape: "Sharp edges detected" if angular
└─ Angle: Estimated viewing angle
```

### Example Captions

```
Caption 1 (Front view):
"Object fills frame | Colors: blue, neutral | Sharp edges | Angle: direct_view"
→ Indicates: Front-facing, 70-90% coverage, sharp features

Caption 2 (Side view):
"Object clearly visible | Colors: red | Textured surface | Size: 65%"
→ Indicates: Side angle, textured, moderate coverage

Caption 3 (Top view):
"Object in frame | Colors: green, cyan | Size: 42% | Angle: top_view_estimate"
→ Indicates: Top-down angle, smaller coverage
```

### What Captions Tell You

```
"Object fills frame" → Good angle, complete coverage
"Sharp edges detected" → Rectangular/angular object
"Textured surface" → Not smooth, has detail
"Colors: multiple" → Varied appearance, good for reconstruction
"Angle: 45°" → Diagonal view (great for 3D accuracy)
```

## 🆘 COMMON ISSUES & QUICK FIXES

### Problem 1: "Video Format Not Supported"
```
Solution:
1. Check file extension: .mp4, .webm, .avi, .mov?
2. If not, convert using online tool or FFmpeg:
   ffmpeg -i video.mkv -c:v libx264 video.mp4
3. Try MP4 format first (most compatible)
```

### Problem 2: "Video Too Large"
```
Solution:
1. Check file size: Is it > 500MB?
2. Compress video:
   ffmpeg -i large.mp4 -crf 28 small.mp4
3. Or trim to 30 seconds:
   ffmpeg -i video.mp4 -t 30 output.mp4
```

### Problem 3: Captions Not Appearing
```
Solution:
1. Check internet connection
2. Check browser console (F12): Any errors?
3. Ensure video is valid (play it locally first)
4. Try smaller test video
5. Refresh page and try again
```

### Problem 4: Processing Very Slow
```
Solution:
1. Reduce keyframes to 5-10
2. Use shorter video (< 20 seconds)
3. Close other browser tabs
4. Try again during off-peak time
5. Check system resources (CPU/RAM)
```

### Problem 5: Captions Say "Processing..."
```
Solution:
1. Wait longer (processing takes 200-400ms per frame)
2. Check backend is running (port 5000)
3. Try extract-to-images mode instead
4. Check browser console for errors
```

## 💡 PRO TIPS

```
Tip 1: Mirror/Reflections
└─ Use for viewing hidden sides
└─ Captions will note reflections
└─ Improves 3D reconstruction

Tip 2: Lighting
└─ Use shadowless light
└─ LED ring light ideal
└─ Avoid harsh shadows

Tip 3: Background
└─ Plain, contrasting background
└─ Helps edge detection
└─ Improves shape recognition

Tip 4: Scale Reference
└─ Use known-size object if ruler unavailable
└─ Coin (25mm), card (85mm), hand (80mm)
└─ Must be clearly visible in video

Tip 5: Multiple Videos
└─ Analyze separately, then combine images
└─ Or extract keyframes from both
└─ Creates more comprehensive model
```
