🔴 INLINE STYLES REMOVAL - ISSUE REPORT & SOLUTION

## Problem Identified

The automated script `remove_remaining_inline_styles.py` used a regex pattern that was too aggressive:

```python
modified_content = re.sub(r'\s*style="[^"]*"', '', content)
```

### Why It Failed

The regex pattern `[^"]*` matches ANY character EXCEPT quotes. However:
- **HTML attributes can contain single/double quotes in their values**
- If any inline style contained a quote, the regex would stop prematurely
- This could corrupt HTML structure or remove critical onclick handlers

### Example of Corruption

BEFORE (safe):
```html
<a onclick="showSection('3Dstudio')" style="color: red">
```

AFTER (broken - style removed successfully):
```html
<a onclick="showSection('3Dstudio')">
```

POTENTIAL PROBLEM (if style had complex value):
```html
<div style="background: url('image.png')">  ← contains quote!
```

Regex stops at FIRST quote, potentially corrupting the onclick or other attributes.

## Better Approach for Future Fixes

To safely remove inline styles WITHOUT breaking onclick handlers:

```python
# SAFE METHOD: Use HTML parser instead of regex
from html.parser import HTMLParser

class StyleRemover(HTMLParser):
    def __init__(self):
        super().__init__()
        self.output = []

    def handle_starttag(self, tag, attrs):
        # Remove style attribute, keep everything else
        clean_attrs = [(k, v) for k, v in attrs if k != 'style']
        # Reconstruct tag with remaining attributes
        attr_str = ' '.join([f'{k}="{v}"' for k, v in clean_attrs])
        self.output.append(f"<{tag} {attr_str}>".rstrip() if clean_attrs else f"<{tag}>")
```
