├─ Agent 4: Launch SSMS → Check execution plan and deadlock graph
├─ Agent 5: Profile with query duration analysis → Identify index issues

SYMPTOM: DLL loading fails
├─ Agent 3: Launch Dependency Walker → Check DLL dependencies
├─ Agent 5: Debug with WinDbg → Analyze load sequence
└─ LIKELY CAUSE: Missing dependency, Version mismatch, or DLL Hell

├─ Agent 1: Profile with memory_profiler → Find allocation hotspots
├─ Agent 5: Analyze with Valgrind/Dr.Memory → Check pointer patterns
└─ LIKELY CAUSE: Circular references, GPU memory not freed, or C ext issue
