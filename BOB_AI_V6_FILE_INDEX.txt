10. SUPPORT & TROUBLESHOOTING
================================================================================

ISSUE: Can't find files
SOLUTION:
  1. Verify current directory: pwd
  2. Check backend directory: ls backend/bob_ai_v6_*.py
  3. Check root directory: ls bob_ai_v6_*.py
  4. Check workspace: ls | grep bob_ai

ISSUE: Import errors
SOLUTION:
  1. Verify Python path: python -c "import sys; print(sys.path)"
  2. Check file permissions: ls -la backend/bob_ai_v6_*.py
  3. Verify Python version: python --version  (should be 3.10+)
  4. Reinstall: python deploy_bob_ai_v6.py --full

ISSUE: Tests failing
SOLUTION:
  1. Run deployment: python deploy_bob_ai_v6.py --full
  2. Check dependencies: pip list | grep -E "(torch|flask)"
  3. Run individual test: python -m pytest test_bob_ai_v6_final.py::TestFineArts -v
  4. Review logs for detailed error messages

ISSUE: Integration not working
SOLUTION:
  1. Verify imports in main.py
  2. Test direct import: python -c "from bob_ai_v6_llm_integration import BobAILLMIntegration; print('OK')"
  3. Check Flask logs
  4. Review examples in bob_ai_v6_llm_integration.py

For more troubleshooting, see:
  • BOB_AI_V6_PRODUCTION_DEPLOYMENT_GUIDE.md (Troubleshooting section)
  • BOB_AI_V6_DEPLOYMENT_CHECKLIST.txt (Troubleshooting section)
