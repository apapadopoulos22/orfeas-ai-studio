TROUBLESHOOTING:
════════════════

Q: "Port 8000 is already in use"
A: Either:
   - Kill existing process using port 8000
   - Use different port: python -m http.server 9000
   - Edit dev_server.py and change PORT = 9000

Q: "Backend shows 'Connection refused'"
A: Check that:
   - Backend is running on port 5000
   - ngrok tunnel is active
   - Both are in separate terminals

Q: "Changes don't appear after refresh"
A: Press hard refresh:
   - Ctrl+Shift+R (Windows)
   - Cmd+Shift+R (Mac)
   - Or clear browser cache

Q: "Where do I edit files?"
A: All files in:
   c:\Users\johng\Documents\oscar\

   Main files:
   - orfeas-ai-studio.html
   - synexa-style-studio.html
   - batch-studio.html
   - (or any HTML file in the root)
