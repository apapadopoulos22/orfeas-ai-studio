TROUBLESHOOTING

→ Solution: pip install sqlalchemy

Issue: Database file not found
→ Solution: Paths are relative to backend/ directory

Issue: API returns 404
→ Solution: Ensure init_bob_ai_expansion_api() called in main.py

Issue: Data not loading
→ Solution: Run data_loader.py with correct CSV file paths

Issue: Import errors in main.py
→ Solution: Copy all 3 .py files to backend/ directory first
