┌────────────────────────────────────────────────────────────────────────────────┐
│ 📞 SUPPORT & TROUBLESHOOTING                                                   │
└────────────────────────────────────────────────────────────────────────────────┘

Backend won't start?
  → Check port 5000 is free: netstat -ano | findstr :5000
  → Check Python is installed: python --version
  → Check dependencies: pip list | grep -i flask
  → Read logs: Get-Content backend/logs/backend_requests.log -Tail 50

Ollama not connecting?
  → Verify Ollama is running: curl http://localhost:11434
  → Check Mistral model: ollama list
  → Pull Mistral if needed: ollama pull mistral

SVG generation fails?
  → Check LLM endpoint: curl http://localhost:5000/api/local-llm/status
  → Check GPU memory: nvidia-smi (if NVIDIA-SMI available)
  → Check logs for errors: Get-Content backend/logs/backend_requests.log -Tail 100

Slow response times?
  → Check GPU utilization: nvidia-smi
  → Check system resources: Get-Process python | Measure-Object -Property WSM
  → Monitor cache hit rate: Check dashboard at /metrics
