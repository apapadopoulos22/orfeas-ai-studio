# ORFEAS Model Cache Fix - Quick Start

## The Issue

Your Hunyuan3D model is trying to download from HuggingFace because:

```text
Try to load model from local path: C:\Users\johng/.cache/hy3dgen\tencent/Hunyuan3D-2\...
Model path not exists, try to download from huggingface
```

**Root cause:** Mixed path separators on Windows (`/` and `\` together)

---

## The Fix (One Command)

Run this **one time**:

```powershell
cd c:\Users\johng\Documents\oscar\backend
python setup_model_cache.py
```

That's it! ✅

---

## Then Start Your Server

```powershell
python main.py
```

The server will now:
- ✅ Load models from correct cache directory
- ✅ Use proper Windows paths (all backslashes)
- ✅ Skip downloads (if models already cached)
- ✅ Start in 30-60 seconds instead of 5-30 minutes

---

## What Was Created

Three helper scripts in `backend/`:

| File | Purpose |
|------|---------|
| `setup_model_cache.py` | Main Python setup script |
| `setup_models.ps1` | PowerShell wrapper |
| `setup_models.bat` | Batch file wrapper |

---

## How It Works

The setup script:

1. **Creates** proper cache directory: `models/.cache/huggingface/`
2. **Configures** environment variables:
   - `HF_HOME` = cache location
   - `TRANSFORMERS_CACHE` = model cache
   - `HY3DGEN_CACHE` = Hunyuan3D cache
3. **Fixes** all path separators (Windows backslashes)
4. **Updates** .env file automatically
