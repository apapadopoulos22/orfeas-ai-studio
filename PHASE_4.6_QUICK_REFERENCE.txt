SECURITY BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

API Key Management
───────────────────
✓ Generate keys securely (use create_key())
✓ Store keys securely (NEVER in source code)
✓ Rotate keys regularly (set expiration)
✓ Revoke unused keys
✓ Use different keys per client/application
✓ Don't share keys between applications

Cache Security
───────────────
✓ Don't cache sensitive data (PII, passwords)
✓ Set appropriate TTLs (shorter for sensitive)
✓ Clear cache on data update
✓ Use encryption for persistent cache (Redis)
✓ Monitor cache hit rates

Rate Limiting
──────────────
✓ Set appropriate limits per client
✓ Monitor usage patterns
✓ Adjust limits based on actual usage
✓ Use same limit for all clients initially
✓ Implement gradual limit increases

Input Validation
─────────────────
✓ Always validate on server side
✓ Never trust client input
✓ Sanitize before storage
✓ Log validation failures
✓ Return generic errors (don't reveal system info)

HTTPS in Production
────────────────────
✓ Always use HTTPS (enforce with HSTS)
✓ Use valid SSL certificates
✓ Set secure cookie flags
✓ Enable CORS restrictions
✓ Use security headers (CSP, X-Frame, etc.)

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Tests Failing
──────────────
Problem: "ImportError: No module named 'phase4_cache_manager'"
Solution: Ensure backend path is in sys.path
  cd backend
  python test_phase4_security.py

Problem: "Redis connection failed"
Solution: Redis is optional, uses in-memory fallback
  Install Redis: pip install redis
  Or use in-memory: get_cache_manager(use_redis=False)

Server Won't Start
────────────────────
Problem: "Address already in use"
Solution: Change port or kill existing process
  # Change port in phase4_secure_app.py
  app.run(port=5001)

  # Or kill process
  lsof -i :5000
  kill -9 <PID>

API Key Not Working
─────────────────────
Problem: "Unauthorized" error
Solution: Check header format
  # Correct
  X-API-Key: bob_ai_...

  # Wrong
  Authorization: Bearer bob_ai_...
  X-Api-Key: bob_ai_...  (wrong case)

Rate Limit Hit Immediately
─────────────────────────────
Problem: Getting "Rate limit exceeded" on first request
Solution: Verify rate limit > 0
  auth.create_key("App", rate_limit=100)  # Good
  auth.create_key("App", rate_limit=0)    # Bad

───────────────

Typical Hit Rates:

Reduce Response Time

✓ Use CDN for static files

Target Response Times:
