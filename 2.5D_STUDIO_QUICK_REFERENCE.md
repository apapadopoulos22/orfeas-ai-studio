## API Endpoints Quick Reference

| Function | Endpoint | Method | Purpose |
|----------|----------|--------|---------|
| handleDesignFile | `/api/design-process` | POST | Validate SVG/DXF/PDF files |
| handleVectorImage | `/api/vector-convert` | POST | Convert image to SVG (Potrace) |
| generateEngraveMap | `/api/engrave-map-generate` | POST | Create depth map from photo |
| sliceModelTo25D | `/api/slice-3d-to-25d` | POST | Slice 3D model to 2.5D layers |
| optimizeForCutting | `/api/optimize-cutting` | POST | Optimize design for cutting |
| optimizeForEngraving | `/api/optimize-engraving` | POST | Optimize design for engraving |
| autoNest | `/api/auto-nest` | POST | Auto-arrange pieces on bed |
| generateToolpath | `/api/generate-toolpath` | POST | Generate GRBL G-Code |
| exportSVG | `/api/export-design` | POST | Export as SVG (Scalable Vector Graphics) |
| exportDXF | `/api/export-design` | POST | Export as DXF (AutoCAD format) |
| exportGCode | `/api/export-design` | POST | Export as G-Code (GRBL compatible) |
| exportPDF | `/api/export-design` | POST | Export as PDF (print-ready) |

## Request/Response Patterns

### Design File Validation

**Frontend Call:**

```javascript
POST /api/design-process
{
  "filename": "design.svg",
  "filetype": "image/svg+xml",
  "content": "<svg>...</svg>",
  "operation": "validate"
}
```

**Expected Response:**

```json
{
  "success": true,
  "width": 500,
  "height": 300,
  "layers": 1,
  "segments": 42
}
```

---

### Vector Conversion (Image → SVG)

**Frontend Call:**

```javascript
POST /api/vector-convert (FormData)
{
  "image": File,
  "quality": "Low|Medium|High"
}
```

**Expected Response:**

```json
{
  "success": true,
  "svgData": "<svg>...</svg>",
  "pathCount": 128,
  "fileSize": "45KB",
  "downloadUrl": "/downloads/vector_123456.svg"
}
```

---

### Engraving Map Generation

**Frontend Call:**

```javascript
POST /api/engrave-map-generate
{
  "imageData": "data:image/png;base64,...",
  "contrast": 120,
  "depth": 75
}
```

**Expected Response:**

```json
{
  "success": true,
  "depthMapUrl": "/previews/engrave_123456.png",
  "estimatedTime": "12 minutes",
  "downloadUrl": "/downloads/engrave_123456.png"
}
```

---

### 3D to 2.5D Slicing

**Frontend Call:**

```javascript
POST /api/slice-3d-to-25d
{
  "modelUrl": "/models/generated_model.stl",
  "layerHeight": 2.5,
  "material": "wood",
  "bedWidth": 500,
  "bedHeight": 300
}
```

**Expected Response:**

```json
{
  "success": true,
  "layers": [
    {
      "layerNum": 1,
      "previewUrl": "/previews/layer_1.png",
      "svgUrl": "/models/layers/layer_1.svg"
    }
  ],
  "totalHeight": 42.5,
  "downloadUrl": "/downloads/sliced_layers_123456.zip"
}
```

## Error Response Pattern

**All endpoints should return errors as:**

```json
{
  "success": false,
  "error": "Detailed error message",
  "code": "ERROR_CODE"
}
```

**Frontend handles with:**

```javascript
if (!response.ok) throw new Error(`Operation failed: ${response.statusText}`);
// Shows user-friendly alert
// Logs to console for debugging
```
