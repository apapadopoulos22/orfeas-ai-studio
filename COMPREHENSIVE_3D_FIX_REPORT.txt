Scenario 1: "Model doesn't appear at all"

    1. Open browser DevTools (F12)
    2. Look for JavaScript errors in console
    3. Verify backend is responding: Check Network tab

  Solution:

    - Check backend logs for error messages
    - Verify file permissions on output folder

Scenario 2: "Canvas is gray/blank"
  Check:
    1. Confirm Three.js initialized: Look for "[3D] scene initialized"
    2. Verify model loaded: Look for "[3D] STL loaded"
  Solution:
    - Check if lighting is disabled
    - Verify camera position is correct
    - Try zooming out (scroll wheel)

Scenario 3: "Model appears but isn't interactive"
  Check:
    1. Browser console for OrbitControls errors
    2. Network tab - confirm JS libraries loaded
  Solution:
    - Refresh page
    - Clear browser cache (Ctrl+Shift+Delete)
    - Try different browser

Scenario 4: "Model rotates too fast/slow"
  Check:
    1. If too fast: Set autoRotateSpeed to lower value
    2. If too slow: Set autoRotateSpeed to higher value
  Solution:
    - Adjust controls.autoRotateSpeed (currently 2 RPM)
    - Disable with controls.autoRotate = false

Scenario 5: "Performance is stuttering (low FPS)"
  Check:
    1. Run nvidia-smi to check GPU memory
    2. Check other GPU applications
  Solution:
    - Close other 3D applications
    - Reduce quality slider (if available)
    - Check GPU memory usage
    - Try smaller model
