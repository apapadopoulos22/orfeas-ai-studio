## 🚀 QUICK START (3 MINUTES)

### Step 1: Understand Your Need
Use the **decision tree** in REPLICATOR_EXPORT_FORMATS_QUICK_REFERENCE.txt

### Step 2: Upload & Analyze
1. Go to Replicator → Video tab
2. Upload video
3. Wait for analysis
4. See "Export Options" section

### Step 3: Select Format
Click dropdown and choose:
- **OBJ** → Web/preview
- **STL** → 3D printing
- **STEP** → CAD/engineering
- **Parasolid** → Enterprise

### Step 4: Export
Click "Export 3D Model" → File downloads

### Step 5: Use File
Open in appropriate software:
- OBJ: Three.js, Babylon.js, any viewer
- STL: Cura, PrusaSlicer, 3D printer
- STEP: Fusion 360, SolidWorks, AutoCAD
- Parasolid: NX, TeamCenter

## 💡 COMMON WORKFLOWS

### Workflow A: 3D Printing (5 minutes)
```
1. Record 30-60s video with ruler
2. Upload to Replicator
3. Wait ~10 seconds
4. Export as STL
5. Open in Cura
6. Print!
```
→ **See:** REPLICATOR_EXPORT_FORMATS_QUICK_REFERENCE.txt

### Workflow B: CAD Design (15 minutes)
```
1. Upload video to Replicator
2. Wait for analysis
3. Export as STEP
4. Import to Fusion 360
5. Modify and combine
6. Generate CAM code
```
→ **See:** REPLICATOR_EXPORT_FORMATS_GUIDE.md (Section: Workflow 2)

### Workflow C: Enterprise (30 minutes)
```
1. Analyze product video
2. Export as Parasolid
3. Import to NX
4. Add to assembly
5. Run FEA
6. Archive in PLM
```
→ **See:** REPLICATOR_EXPORT_FORMATS_GUIDE.md (Section: Workflow 3)

### Workflow D: Web Share (2 minutes)
```
1. Export as OBJ
2. Upload to web server
3. Embed in Three.js
4. Share link
5. Collaborate
```
→ **See:** REPLICATOR_EXPORT_FORMATS_QUICK_REFERENCE.txt

## ❓ FAQ - QUICK ANSWERS

**Q: Which format should I use?**
A: See "Format Picker" in REPLICATOR_EXPORT_FORMATS_QUICK_REFERENCE.txt

**Q: How do I 3D print my model?**
A: Export as STL, open in Cura/PrusaSlicer, print. Full guide in guide.md

**Q: Can I use this in CAD software?**
A: Yes! Export as STEP (professional standard). See guide.md

**Q: What's Parasolid used for?**
A: Enterprise CAD systems (NX, TeamCenter). See guide.md Section 4

**Q: Which format is smallest?**
A: OBJ and STL (~2-4 KB). See comparison table in quick-reference.txt

**Q: Can I convert between formats?**
A: Yes, use FreeCAD or Fusion 360. Details in guide.md
