Step 2: Create Knowledge Graph (5 minutes)
------------------------------------------

# Create Python script to initialize graph:

```python
from sqlalchemy.orm import sessionmaker
from backend.bob_ai_expansion_phase1_database import initialize_bob_ai_expansion
from backend.bob_ai_expansion_phase2_knowledge_graph import initialize_knowledge_graph
from backend.bob_ai_expansion_phase2_search import AdvancedSearchEngine

# Initialize database (Phase 1)
database_url = 'sqlite:///./bob_ai.db'
loader = initialize_bob_ai_expansion(database_url)
loader.connect()
Session = loader.Session

# Initialize knowledge graph (Phase 2)
session = Session()
graph, analyzer, recommendation_engine = initialize_knowledge_graph(session)

if graph:
    print("✅ Knowledge graph initialized successfully!")
    print(f"   Nodes: {graph.number_of_nodes()}")
    print(f"   Edges: {graph.number_of_edges()}")
else:
    print("❌ Failed to initialize knowledge graph")

session.close()
```

Save as: `backend/init_phase2.py`
Run: `python backend/init_phase2.py`


Step 3: Integrate with main.py (5 minutes)
-------------------------------------------

# Add after Phase 1 initialization (around line 170 in main.py):

```python
# [BOB AI EXPANSION] Initialize Phase 2 - Knowledge Graph & Search
try:
    from bob_ai_expansion_phase2_knowledge_graph import initialize_knowledge_graph
    from bob_ai_expansion_phase2_search import AdvancedSearchEngine
    from bob_ai_expansion_phase2_api import init_bob_ai_phase2_api

    # Initialize knowledge graph
    graph, analyzer, recommendation_engine = initialize_knowledge_graph(expansion_loader.Session())

    if graph and analyzer:
        # Initialize search engine
        search_engine = AdvancedSearchEngine(expansion_loader.Session(), use_elasticsearch=False)

        # Register Phase 2 API
        init_bob_ai_phase2_api(app, expansion_loader.Session, analyzer, recommendation_engine, search_engine)

        logger.info("✅ BOB AI Expansion Phase 2 initialized (knowledge graph + search)")
    else:
        logger.warning("⚠️  Knowledge graph not initialized. Phase 2 features disabled.")

except ImportError as e:
    logger.warning(f"Phase 2 not available: {e}")
except Exception as e:
    logger.error(f"Phase 2 initialization error: {e}")
```


NEW API ENDPOINTS (Phase 2)
==========================

KNOWLEDGE GRAPH ANALYSIS
------------------------

1. GET /api/v2/graph/analyze/{discipline_id}
   Returns:
   {
     "discipline_id": 42,
     "prerequisites": [1, 5, 12],
     "prerequisites_count": 3,
     "related_disciplines": [
       {"discipline_id": 43, "relationship_strength": 0.85},
       {"discipline_id": 44, "relationship_strength": 0.72}
     ],
     "network_metrics": {
       "centrality": 0.234,
       "pagerank": 2.45,
       "importance_rank": "High"
     }
   }

2. GET /api/v2/graph/prerequisites/{discipline_id}
   Returns ordered prerequisite chain with difficulty progression


RECOMMENDATIONS
---------------

3. GET /api/v2/recommendations?completed=1,5,12&difficulty=progressive&limit=5
   Returns:
   {
     "recommendations": [
       {
         "discipline_id": 15,
         "discipline_name": "Quantum Algorithms",
         "score": 0.92,
         "reason": "high-impact + relates-to-3-completed",
         "prerequisite_gaps": [],
         "estimated_hours": 12.5,
         "similar_disciplines": ["Quantum Computing", "Algorithms"]
       },
       ...
     ]
   }


LEARNING PATHS
--------------

4. GET /api/v2/learning-paths/optimized/{target_id}?current_level=beginner
   Returns optimized path with:
   - All disciplines in order
   - Total hours and difficulty progression
   - Critical path analysis
   - Parallel learning opportunities
   - Estimated completion time (weeks)


SKILL GAP ANALYSIS
------------------

5. POST /api/v2/skill-gaps/analyze/{target_id}
   Body: {"skills": ["Python", "Statistics", "Data Engineering"]}
   Returns:
   {
     "target_discipline": "Machine Learning Advanced",
     "user_skills": ["Python", "Statistics"],
     "target_skills": ["Python", "Statistics", "Deep Learning", "MLOps"],
     "missing_skills": ["Deep Learning", "MLOps"],
     "gap_count": 2,
     "skill_coverage": 0.5,
     "recommended_disciplines_for_gaps": {
       "Deep Learning": [25, 26, 27],
       "MLOps": [40, 41]
     }
   }


ADVANCED SEARCH
---------------

6. POST /api/v2/search/advanced
   Body:
   {
     "query": "machine learning python",
     "filters": {
       "difficulty": ["intermediate", "advanced"],
       "languages": ["python"],
       "estimated_hours_max": 40
     },
     "limit": 20
   }
   Returns search results with:
   - Full-text relevance scoring (0-1)
   - Facets for refining search
   - Execution time (typically <100ms)

7. GET /api/v2/search/by-skill?skills=Python,Data%20Science
   Find disciplines teaching specific skills

8. GET /api/v2/search/by-industry?industry=Finance
   Find disciplines relevant to specific industry

TROUBLESHOOTING
===============

Issue: "NetworkX not installed"
Solution: pip install networkx

Issue: Knowledge graph not initializing
Cause: Phase 1 database not loaded with data
Solution: Run Phase 1 data loading first

Issue: Elasticsearch connection fails
Cause: Elasticsearch server not running
Solution:
  Option 1: Start Elasticsearch (brew services start elasticsearch)
  Option 2: Use SQL backend (set use_elasticsearch=False)
  Option 3: Install locally: docker run -d -p 9200:9200 docker.elastic.co/elasticsearch/elasticsearch:8.0.0

Issue: Slow recommendations
Cause: Large graph (1000+ nodes)
Solution:
  - Implement graph caching
  - Use incremental updates instead of full rebuild
  - Consider distributed graph database (Neo4j) for Phase 3
