→ **Use OBJ**

## 🔧 FORMAT SPECIFICATIONS

### OBJ (Wavefront)
- **Extension:** .obj
- **Type:** Text, ASCII
- **Size:** Small (compact)
- **Best for:** Web, visualization, quick preview
- **Software:** All 3D software
- **Precision:** ±0.1mm
- **Support:** Universal (95%+)
- **Print ready:** No (needs conversion)
- **CAD ready:** No (basic geometry only)

### STL (Stereolithography)
- **Extension:** .stl
- **Type:** Text, ASCII format (not binary)
- **Size:** Small
- **Best for:** 3D printing, rapid prototyping
- **Software:** All slicing software (Cura, Prusaslicer)
- **Precision:** ±0.5mm (typical)
- **Support:** All 3D printers
- **Print ready:** ✅ YES (direct to printer)
- **CAD ready:** No (triangles only)

### STEP (Standard for Exchange of Product Data)
- **Extension:** .step or .stp
- **Type:** Text, ISO 10303-21 format
- **Size:** Medium
- **Best for:** Professional CAD, manufacturing
- **Software:** Fusion 360, SolidWorks, Inventor, AutoCAD
- **Precision:** ±0.001mm (CAD standard)
- **Support:** All professional CAD systems
- **Print ready:** No (needs slicing)
- **CAD ready:** ✅ YES (full CAD compatibility)

### Parasolid (Professional CAD Kernel)
- **Extension:** .x_t (text) or .x_b (binary)
- **Type:** Proprietary but standardized
- **Size:** Medium
- **Best for:** Enterprise CAD, aerospace, complex assemblies
- **Software:** NX, Siemens Teamcenter, SAP PLM
- **Precision:** Perfect topology preservation
- **Support:** Enterprise CAD systems
- **Print ready:** No
- **CAD ready:** ✅ YES (enterprise-grade)

## 💡 PRO TIPS

### For 3D Printing
1. **Always check manifold** - Use Netfabb to verify solid
2. **Optimize orientation** - Minimize support material
3. **Test print first** - Do a 1:4 scale test
4. **Use appropriate infill** - 15% typical, 100% for functional parts
5. **Check print time** - Large models take 6-12 hours

### For CAD/CAM
1. **Verify units** - Confirm mm vs. inches
2. **Include reference plane** - Document Z=0
3. **Check dimensions** - Measure against original
4. **Document assumptions** - Material, tolerances
5. **Archive originals** - Keep STEP files long-term

### For Enterprise
1. **Follow PDM procedures** - Check into PLM system
2. **Document source** - Link to video/analysis
3. **Add metadata** - Material, scale, accuracy
4. **Version control** - Track iterations
5. **Audit trail** - Keep export logs

### For Web
1. **Compress geometry** - Reduce polygon count
2. **Optimize for web** - Check file size
3. **Test cross-browser** - Chrome, Firefox, Safari
4. **Use CORS properly** - Enable cross-origin access
5. **Host on CDN** - For fast downloads

## ❓ FAQ

**Q: Which format is smallest?**
A: OBJ and STL are roughly equal, both 2-5 KB for simple models.

**Q: Which format is most accurate?**
A: STEP and Parasolid both preserve ±0.001mm precision.

**Q: Can I convert between formats?**
A: Yes! Use software like FreeCAD, Fusion 360, or online converters.

**Q: Which is best for my first 3D print?**
A: STL is the only format 3D printers understand natively.

**Q: Can I edit OBJ in CAD software?**
A: No, but you can view and convert it. Use STEP for editing.

**Q: Is Parasolid better than STEP?**
A: Both are excellent. Parasolid is better for enterprise workflows.

**Q: How do I verify export quality?**
A: Open in viewer, check all faces, verify dimensions, run slicing preview.

**Q: Which format for 3D printing services?**
A: STL (standard requirement for online 3D printing services).
