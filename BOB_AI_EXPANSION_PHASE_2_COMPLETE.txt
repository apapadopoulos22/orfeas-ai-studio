TECHNICAL SPECIFICATIONS
========================

Knowledge Graph Engine:
  - Library: NetworkX 3.0+
  - Graph type: Directed acyclic graph (DAG)
  - Algorithms: DFS (prerequisites), PageRank, betweenness centrality
  - Community detection: Greedy modularity optimization
  - Construction time: ~2 seconds for 891 nodes
  - Memory: ~10-20 MB for typical dataset

Recommendation Engine:
  - Algorithm: Multi-factor scoring (PageRank + prerequisites + relationships)
  - Scoring factors:
    * PageRank importance (0.3 weight)
    * Prerequisite satisfaction (0.4 weight)
    * Relationship to completed (0.2 weight)
    * Difficulty progression (0.1 weight)
  - Output: Ranked list with scores 0-1
  - Performance: <500ms per recommendation set

Search Engine:
  - SQL Backend: Full-text search with Ilike pattern matching
  - Relevance scoring: Name match (1.0) > partial name (0.8) > content (0.4) > keywords (0.3)
  - Faceting: Dynamic facet generation from results
  - Elasticsearch Backend: BM25 scoring algorithm, full-text analysis
  - Performance (1000 documents):
    * SQL: 50-100ms average
    * Elasticsearch: 10-20ms average

API Response Times (target):
  - Graph analysis: <200ms
  - Recommendations: <500ms
  - Learning paths: <300ms
  - Skill gap analysis: <200ms
  - Search: <100ms (SQL), <20ms (Elasticsearch)
