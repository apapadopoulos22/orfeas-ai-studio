📡 API ENDPOINT
═════════════════════════════════════════════════════════════════════════════════

POST /api/optimize-halotbox

Request Parameters:
  {
    "job_id": "string (required)",
    "material": "standard|surgical|jewel|model|castable|flexible",
    "quality": "fast|standard|high|ultra",
    "auto_repair": true/false,
    "generate_supports": true/false
  }

Response Includes:
  ✓ success (boolean)
  ✓ optimization_report (detailed analysis)
  ✓ print_parameters (material profile)
  ✓ warnings (issues found)
  ✓ estimated_print_time_hours
  ✓ estimated_resin_ml
  ✓ model_bounds_mm
  ✓ configuration_json (for HalotBox Program)

🔧 HOW TO USE
═════════════════════════════════════════════════════════════════════════════════

STEP 1: Generate 3D Model
  → POST /api/generate-3d (existing endpoint)
  → Get job_id + STL file

STEP 2: Optimize for HalotBox (NEW)
  → POST /api/optimize-halotbox
  → Select material & quality
  → Receive optimization report

STEP 3: Review Report
  → Check warnings & recommendations
  → View print time estimate
  → See resin volume estimate
  → Get material parameters

STEP 4: Download & Print
  → Download optimized STL
  → Open in HalotBox Program
  → Import configuration JSON
  → Print!
