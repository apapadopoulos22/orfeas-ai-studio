TROUBLESHOOTING
===============

Issue: Backend won't start
  Solution: taskkill /F /IM python.exe
           netstat -ano | findstr :5000
           Check for port conflicts

Issue: CORS errors in browser
  Solution: Run CORS_TEST_FRONTEND.html
           Check CORS headers in F12 Network tab
           Verify CORS_ORIGINS in .env

Issue: Slow response times
  Solution: Check nvidia-smi for GPU usage
           Verify GPU_MEMORY_LIMIT setting
           Check for competing processes

Issue: GPU out of memory
  Solution: Reduce MAX_CONCURRENT_JOBS to 2
           Reduce GPU_MEMORY_LIMIT to 0.75
           Restart backend
