## 🧠 What's Included

### 3 Reasoning Principles

1. **Transparency in Problem-Solving**
   - Explain: WHAT, WHY, HOW, WHAT could go wrong, HOW to verify
   - When: Every decision, every change

2. **Root Cause Before Symptoms**
   - Find actual problems, not symptoms
   - When: Debugging anything

3. **Evidence-Based Decision Making**
   - Collect evidence FOR and AGAINST each decision
   - When: Making decisions

### 3 Error Patterns (Learn from Mistakes)

1. **Pattern 1: Import-Time Configuration**
   - Discovered: xformers crashes when env vars set after import
   - Solution: Set env vars BEFORE imports

2. **Pattern 2: Inline Styles**
   - Discovered: Inline styles hide accessibility issues
   - Solution: Use CSS classes

3. **Pattern 3: Missing Type Hints**
   - Discovered: Untyped functions cause cascading errors
   - Solution: Add full type hints
