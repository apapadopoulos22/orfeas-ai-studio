🔧 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

Endpoint 1: POST /api/replicator/analyze-video
────────────────────────────────────────────────────────────────────────────

Request:
  Content-Type: multipart/form-data

  Parameters:
  ├─ video (required): Video file
  ├─ target_frames (optional, default: 15): 5-30 keyframes
  ├─ has_ruler (optional, default: false): Ruler visible
  └─ ruler_type (optional): "auto", "cm_ruler", etc.

Response (200):
  {
    "success": true,
    "video_id": "abc12345",
    "total_frames": 300,
    "analyzed_frames": 15,
    "fps": 30.0,
    "duration_seconds": 10.0,
    "captions": [...],
    "statistics": {...},
    "recommended_frames": [...]
  }

WebSocket Events:
  ├─ video_analysis_progress (real-time)
  ├─ video_caption_complete (when done)
  └─ video_caption_error (on error)


Endpoint 2: POST /api/replicator/video-to-images
────────────────────────────────────────────────────────────────────────────

Request:
  Content-Type: multipart/form-data

  Parameters:
  ├─ video (required): Video file
  └─ target_frames (optional, default: 10): Frame count

Response (200):
  {
    "success": true,
    "keyframes_extracted": 10,
    "images": [
      {
        "frame_number": 0,
        "timestamp_seconds": 0.0,
        "filename": "keyframe_000.png",
        "path": "..."
      },
      ...
    ],
    "temp_dir": "/path/to/images"
  }
