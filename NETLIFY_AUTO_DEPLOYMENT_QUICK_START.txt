OPTION 1: AUTOMATED SETUP (RECOMMENDED - 5 minutes)
───────────────────────────────────────────────

Run this command:
  .\NETLIFY_AUTO_DEPLOY_SETUP.ps1

The script will:
  ✓ Check Git installation
  ✓ Initialize Git repository
  ✓ Commit Netlify files
  ✓ Guide GitHub connection
  ✓ Configure Netlify automatically

Result: Automatic deployment enabled!


OPTION 2: MANUAL SETUP (10 minutes)
──────────────────────────────

A. Initialize Git locally
   git init
   git add .
   git commit -m "Initial commit"

B. Create GitHub repository
   → Visit: https://github.com/new
   → Create repository
   → Copy URL

C. Push to GitHub
   git remote add origin YOUR_REPO_URL
   git branch -M main
   git push -u origin main

D. Connect to Netlify
   → Visit: https://app.netlify.com
   → Sign in with GitHub
   → Click: New site from Git
   → Select repository
   → Deploy!

E. Add environment variables
   → Netlify Dashboard → Settings → Environment variables
   → Add from .env.netlify


OPTION 3: QUICK DEPLOY SCRIPT (3 minutes)
────────────────────────────────

Windows:
  .\DEPLOY_NETLIFY.bat

PowerShell:
  .\DEPLOY_NETLIFY.ps1

Mac/Linux:
  bash NETLIFY_AUTO_DEPLOY_SETUP.sh

✅ CHECKLIST BEFORE FIRST DEPLOYMENT

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before deploying to production:

  □ netlify.toml exists and is valid
  □ .env.netlify configured with backend URL
  □ netlify/functions/ contains api.js and health.js
  □ orfeas-ai-studio.html accessible
  □ Git repository initialized (git init)
  □ Files committed (git commit)
  □ GitHub account created
  □ GitHub repository created
  □ GitHub remote configured (git remote add origin ...)
  □ Netlify account created
  □ Netlify site connected to GitHub repo
  □ Environment variables added to Netlify
  □ Backend service is running
  □ CORS configured correctly
  □ SSL certificate valid
