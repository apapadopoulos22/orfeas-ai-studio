TROUBLESHOOTING QUICK REFERENCE
================================

ISSUE: Module import error
FIX:
  1. Verify files in backend directory: ls backend/bob_ai_v6_*.py
  2. Check Python path: python -c "import sys; print(sys.path)"
  3. Reinstall: python deploy_bob_ai_v6.py --full

ISSUE: Tests failing
FIX:
  1. Run individual test: python -m pytest test_bob_ai_v6_final.py::TestFineArts -v
  2. Check dependencies: pip list | grep -E "(torch|flask)"
  3. Reinstall requirements: pip install -r requirements.txt

ISSUE: Domain not detected
FIX:
  1. Test detection directly: python -c "
     from bob_ai_v6_integration import FinalComprehensiveEnhancer
     e = FinalComprehensiveEnhancer()
     print(e.detect_knowledge_domain('boxing and robotics'))
     "
  2. Check keywords in bob_ai_v6_integration.py
  3. Restart Flask service

ISSUE: LLM timeout
FIX:
  1. Check Ollama: curl http://localhost:11434/api/tags
  2. Check Mistral: ollama list
  3. Restart Ollama service
  4. Restart Flask backend

ISSUE: WebSocket not working
FIX:
  1. Check Socket.IO: curl http://localhost:5000/socket.io/
  2. Review Flask logs for WebSocket errors
  3. Check network connectivity
  4. Verify room/session_id parameters
