## Format Details

### 1. OBJ (Wavefront OBJ)

**Best for:** Web viewers, 3D visualization, cross-platform compatibility

**Technical Specs:**

- Format: Text-based ASCII
- Supported by: Virtually all 3D software
- Geometry support: Vertices, normals, textures, faces
- File size: Compact
- Extension: `.obj`

**Use Cases:**

- Web-based 3D viewers (Three.js, Babylon.js)
- Game engines (Unity, Unreal)
- 3D printing slicers (supplementary)
- General 3D visualization

**Advantages:**
✅ Universal support across all platforms
✅ Human-readable format
✅ Includes normals and UVs
✅ Smallest file size
✅ Fastest processing

**Limitations:**
❌ Not ideal for CAD manufacturing
❌ Limited metadata support
❌ Single-part models only

**Example File Structure:**

```
# Wavefront OBJ generated by ORFEAS Replicator
mtllib default.mtl
usemtl default

v 0.0 0.0 0.0      # Vertex
v 100.0 0.0 0.0
v 100.0 100.0 0.0
v 0.0 100.0 0.0

vn 0 0 1           # Vertex normal
f 1//1 2//1 3//1   # Face with normal reference

usemtl default
f 1 2 3 4
```

### 2. STL (Stereolithography)

**Best for:** 3D printing, additive manufacturing, rapid prototyping

**Technical Specs:**

- Format: ASCII (text) or Binary
- ORFEAS exports: ASCII STL
- Geometry support: Triangular facets only
- File size: Small
- Extension: `.stl`

**Use Cases:**

- FDM 3D printers (Ultimaker, Prusa)
- SLA/DLP printers (Formlabs, 3D Systems)
- Slicing software (Cura, PrusaSlicer, SuperSlicer)
- 3D printing services
- Rapid prototyping workflows

**Advantages:**
✅ Industry standard for 3D printing
✅ Supported by all slicing software
✅ ASCII format is readable and debuggable
✅ No metadata overhead
✅ Direct import to printer firmware

**Limitations:**
❌ Only triangular faces (no NURBS or complex surfaces)
❌ No color/material information
❌ No texture support
❌ Can produce large file sizes with fine detail

**Example Workflow:**

```
1. Export model as STL from Replicator
2. Open in slicing software (Cura, PrusaSlicer)
3. Position and scale model
4. Configure print settings (layer height, infill, support)
5. Generate G-code
6. Send to 3D printer
```

**Recommended Printer Settings:**

- Layer height: 0.1-0.2mm (standard), 0.05mm (fine detail)
- Infill: 15-20% (typical), 100% (strength-critical parts)
- Support: Generate if overhangs > 45°
- Nozzle temp: 200-220°C (PLA), 230-250°C (PETG)
- Bed temp: 60°C (PLA), 80°C (PETG)

### 3. STEP (Standard for Exchange of Product Data)

**Best for:** Professional CAD/CAM workflows, manufacturing, engineering

**Technical Specs:**

- Format: ISO 10303-21 standard
- File type: Text-based with structured data
- Geometry support: Solids, surfaces, wireframes, NURBS
- File size: Large
- Extension: `.step` or `.stp`
- MIME type: `application/step`

**Use Cases:**

- CAD software (Fusion 360, SolidWorks, AutoCAD)
- Manufacturing (CNC, machining, fabrication)
- Design review and collaboration
- Bill of Materials (BOM) generation
- Quality assurance and compliance
- Assembly and simulation workflows

**Advantages:**
✅ Industry standard (ISO approved)
✅ Rich metadata and assembly information
✅ Supports complex geometries
✅ Compatible with all professional CAD systems
✅ Maintains dimensional accuracy
✅ Supports constraints and relationships
✅ Version control friendly

**Limitations:**
❌ Larger file sizes than OBJ/STL
❌ More complex parsing required
❌ Software-dependent implementation details
❌ Not suitable for web viewing

**Compatible Software:**

- **Professional CAD:**
  - Autodesk Fusion 360, AutoCAD, Inventor
  - SolidWorks / SOLIDWORKS Premium
  - Siemens NX, Catia
  - PTC Creo, Pro/Engineer
- **Open Source:**
  - FreeCAD (full support)
  - LibreCAD (partial)
  - OpenSCAD (import)
- **Manufacturing:**
  - CAM software (Mastercam, Fusion 360)
  - CNC controllers
  - Robot programming systems

**Example Workflow:**

```
1. Export model as STEP from Replicator
2. Import into CAD software
3. Combine with other components
4. Create assemblies and constraints
5. Prepare for manufacturing
6. Generate CNC toolpaths
7. Manufacture physical part
```

**STEP Format Advantages for Manufacturers:**

- Precise dimensional data preserved
- Surface quality information maintained
- Assembly structure encoded
- Can include manufacturing notes
- Audit trail and version history supported

### 4. Parasolid (Professional CAD Kernel)

**Best for:** Advanced CAD systems, professional manufacturing, enterprise workflows

**Technical Specs:**

- Format: Parasolid XT (text format, binary format available)
- File type: Proprietary but widely standardized
- Geometry support: Solids, surfaces, complex assemblies
- File size: Large
- Extension: `.x_t` (text) or `.x_b` (binary)
- Industry: Aerospace, automotive, heavy machinery

**Use Cases:**

- Advanced CAD systems integration
- Complex assembly management
- Aerospace and automotive design
- Enterprise manufacturing systems
- Multi-part assembly workflows
- High-precision engineering
- Simulation and FEA preparation

**Advantages:**
✅ Most robust 3D modeling kernel
✅ Superior topology preservation
✅ Advanced surface modeling
✅ Complex assembly support
✅ Enterprise-grade stability
✅ Broad industry adoption
✅ Multi-body solid modeling

**Limitations:**
❌ Proprietary format (requires licensed software)
❌ Largest file sizes
❌ Steepest learning curve
❌ Limited open-source support
❌ Not for web visualization

**Compatible Systems:**

- **Primary:**
  - Siemens NX (uses Parasolid kernel)
  - Autodesk Inventor (history)
  - Various PLM systems
- **Secondary:**
  - CATIA V5
  - Pro/Engineer
  - SolidWorks (legacy integration)
- **Enterprise:**
  - SAP PLM
  - Windchill
  - TeamCenter
  - Enovia systems

**Professional Workflow:**

```
1. Export model as Parasolid from Replicator
2. Import into NX or enterprise CAD system
3. Perform advanced analysis (FEA, CFD, etc.)
4. Create detailed manufacturing drawings
5. Generate complex CNC programs
6. Manage supply chain and documentation
7. Archive in PLM system
```

## Format Selection Guide

### Choose OBJ if you

- ✅ Need universal compatibility
- ✅ Want fast processing and small file sizes
- ✅ Plan to view in web browsers or game engines
- ✅ Need quick previews and iterations
- ✅ Working with graphics/visualization teams

**Quick command to verify OBJ:**

```bash
head -20 model.obj
```

---

### Choose STL if you

- ✅ Planning to 3D print the model
- ✅ Using any slicing software (Cura, PrusaSlicer)
- ✅ Working with FDM or resin printers
- ✅ Need rapid prototyping
- ✅ Want direct import to printer firmware

**Quick verification:**

```bash
file model.stl
head -5 model.stl
```

---

### Choose STEP if you

- ✅ Working with professional CAD software
- ✅ Need precise manufacturing specifications
- ✅ Collaborating with engineering teams
- ✅ Planning CNC machining or fabrication
- ✅ Creating detailed technical drawings
- ✅ Integrating into PLM systems

**Professional workflow:**

```
Replicator (STL) → Import to CAD
→ Add features → Generate drawings
→ CNC toolpath → Manufacture
```

---

### Choose Parasolid if you

- ✅ Using enterprise CAD systems (NX, Teamcenter)
- ✅ Managing complex assemblies
- ✅ Aerospace or automotive engineering
- ✅ Advanced FEA/CFD simulations needed
- ✅ Enterprise PLM integration required
- ✅ High-precision manufacturing workflows

## Implementation Details

### Backend Export Functions

**File:** `backend/main.py`

**Export Endpoints:**

1. `generate_stl_mesh(data)` - Creates ASCII STL format
2. `generate_step_mesh(data)` - Creates STEP CAD format
3. `generate_parasolid_mesh(data)` - Creates Parasolid .x_t format
4. `generate_simple_mesh_obj(data)` - Creates OBJ format (existing)

**HTTP Response Headers:**

```
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="model.ext"
```

### Frontend Export Selector

**File:** `orfeas-ai-studio.html`

**HTML Element:**

```html
<select id="replicator-export-format">
  <option value="obj">OBJ (Wavefront)</option>

  <option value="step">STEP (CAD/CAM)</option>

```

## Troubleshooting

### Issue: "Export failed"

**Solutions:**

1. Check analysis data exists (complete analysis first)
2. Verify internet connection
3. Clear browser cache
4. Try different format
5. Check browser console (F12) for errors

### Issue: "STL file won't slice"

**Solutions:**

1. Check for manifold errors: use Netfabb (free)
2. Repair geometry: Use model repair tool
3. Ensure solid vs. surface (must be solid)
4. Check normals orientation (all outward)

### Issue: "STEP file won't import in CAD"

**Solutions:**

1. Verify CAD software supports STEP AP203
2. Try opening in FreeCAD first (diagnostics)
3. Check file size (if >500MB, may need reduction)
4. Consult CAD software documentation

### Issue: "Parasolid file not recognized"

**Solutions:**

1. Ensure NX or compatible system installed
2. Check .x_t file extension (not .x_b)
3. Verify license for Parasolid kernel
4. Try importing as generic model first

## Format Standards & References

### OBJ Specification

- **Official:** Wavefront Technologies
- **Spec:** Publicly available
- **Support:** Virtually universal

### STL Specification

- **Official:** 3D Systems
- **Spec:** Well-documented, public domain
- **Support:** All 3D printing software

### STEP Specification

- **Official:** International Organization for Standardization (ISO)
- **Standard:** ISO 10303 (STEP)
- **Parts:**
  - Part 21: Exchange mechanism
  - Part 242: Application modules
- **Support:** All professional CAD

- **Format:** Proprietary (licensed)
- **Documentation:** Available to licensees
- **Support:** Professional CAD systems
