API REFERENCE - QUICK LOOKUP
================================================================================

IMPORT:
  from bob_ai_advanced_enhancer import PromptEnhancementPipeline
  from bob_ai_advanced_enhancer import AdvancedPromptEnhancer

FUNCTION 1: Full Enhancement (Default)
  enhanced = PromptEnhancementPipeline.apply_full_enhancement(
      prompt="Your prompt here",
      enhancement_level="high"  # low, medium, high, ultra
  )

FUNCTION 2: Domain-Specific Enhancement
  enhanced, system = PromptEnhancementPipeline.apply_domain_specific_enhancement(
      prompt="Your prompt",
      domain="3d",              # 3d, design, creative, general
      enhancement_level="high"  # low, medium, high, ultra
  )

FUNCTION 3: Context Detection
  context = AdvancedPromptEnhancer.detect_prompt_context(
      prompt="Your prompt"
  )
  # Returns dict with detected design styles, materials, lighting, etc.

FUNCTION 4: Interactive Refinement
  session = PromptEnhancementPipeline.interactive_enhancement_session(
      initial_prompt="Your prompt",
      max_refinements=3
  )
  final = session["final_enhanced"]

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

ISSUE: Enhancement seems minimal
  SOLUTION: Try increasing enhancement level (LOW → HIGH → ULTRA)
  SOLUTION: Use domain-specific enhancement
  SOLUTION: Check context detection: AdvancedPromptEnhancer.detect_prompt_context()

ISSUE: Prompt too long
  SOLUTION: Use lower enhancement level (HIGH → MEDIUM → LOW)
  SOLUTION: Avoid ULTRA level for already-detailed prompts
  SOLUTION: Test output length before deployment

ISSUE: Unexpected enhancement output
  SOLUTION: Verify context detection is working correctly
  SOLUTION: Check that domain selection matches content type
  SOLUTION: Test individual stages separately

ISSUE: Performance concerns
  SOLUTION: Use LOW or MEDIUM levels (5-20ms vs 40-80ms)
  SOLUTION: Avoid ULTRA for high-volume applications
  SOLUTION: Consider caching frequently enhanced prompts
