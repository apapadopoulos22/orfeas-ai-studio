### Step 1: Restart Docker Desktop (2 minutes)

1. **Close Docker Desktop**
   - Right-click Docker icon in system tray → Quit Docker Desktop
   - Wait 10 seconds for full shutdown

2. **Reopen Docker Desktop**
   - Click Start Menu → Search for "Docker"
   - Click "Docker Desktop" to launch
   - Wait 2-3 minutes for initialization
   - You'll see Docker icon become active when ready

3. **Verify Docker is running**

### Option A: Switch to Default Docker Context
```powershell

```

### Option B: Manual Deployment
```powershell

# Start services
docker-compose up -d

# Verify
docker-compose ps
```

### Option C: Reinstall Docker
1. Uninstall Docker Desktop from Control Panel
2. Restart computer
3. Download and install Docker Desktop from docker.com
4. Run deployment script again
