## 🔧 CONFIGURATION QUICK REFERENCE

### netlify.toml Settings

```toml
[build]
  publish = "."                    # Publish current directory
  functions = "netlify/functions"  # Serverless functions
  command = "echo 'Ready'"         # Build command (minimal)

[[redirects]]
  from = "/api/*"                  # Intercept API calls
  to = "/.netlify/functions/api/:splat"  # Forward to function

[[headers]]
  Access-Control-Allow-Origin = "*"      # CORS
  X-Content-Type-Options = "nosniff"     # Security
  Cache-Control = "max-age=3600"         # Cache 1 hour
```

### Environment Variables

```
BACKEND_API=https://your-backend.example.com
API_BASE=https://your-site.netlify.app
ENVIRONMENT=production
CORS_ORIGINS=https://your-site.netlify.app
LOCAL_LLM_ENDPOINT=https://ollama.example.com
LOCAL_LLM_MODEL=mistral
DEVICE=cuda
GPU_MEMORY_LIMIT=0.8
LOG_LEVEL=INFO
```
