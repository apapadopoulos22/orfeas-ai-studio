TROUBLESHOOTING GUIDE
════════════════════════════════════════════════════════════════════════════════

If Text to Image doesn't appear at top:
  → Clear browser cache (Ctrl+Shift+Del)
  → Refresh page (F5 or Ctrl+R)
  → Check console for errors (F12)

If Figurine Enhance creates B&W instead of transparent:
  → Old version cached
  → Force refresh: Ctrl+Shift+R
  → Check line 3166-3170 in HTML file

If background removal isn't working:
  → Adjust threshold slider
  → Try lower threshold (100-150) for darker backgrounds
  → Try higher threshold (180-220) for lighter backgrounds
  → Check image contrast (too low contrast = harder to remove)

If PNG isn't transparent after export:
  → Make sure PNG format selected
  → PNG format is needed to preserve alpha channel
  → JPG format will fill transparency with white
