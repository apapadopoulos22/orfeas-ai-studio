## How It Works

### Automatic Enhancement Pipeline

```
User Input: "Create a minimalist bedroom"
    ↓
[Bob AI Knowledge Base Detects "minimalist"]
    ↓
[Looks up Minimalist Style Dictionary]
    ├─ Design Principles: Clean lines, simple forms, minimal details
    ├─ Materials: Typically wood, concrete, glass
    ├─ Colors: Neutral, monochromatic, desaturated
    ├─ Lighting: Professional, ambient, clean
    ├─ Composition: Balanced, symmetrical, uncluttered
    └─ Quality: High detail, clean execution
    ↓
[Enriches Prompt]
    ↓
Enhanced: "Create a minimalist bedroom, high quality, minimalist style
(Clean lines, simple geometric forms, minimal details, spacious
composition), professionally rendered, studio lighting, detailed"
    ↓
[Sends to Ollama + Mistral LLM with System Prompt containing all KB knowledge]
    ↓
LLM Response: Rich, detailed, semantically correct description
```

### Integration Points

**All API endpoints automatically use enhancement:**
- `/api/text-to-3d` - Auto-enhancement on text input
- `/api/text-to-image` - Auto-enhancement on prompts
- `/api/image-enhance` - Auto-enhancement on descriptions
- WebSocket events - Real-time enhancement
- Background tasks - Batch enhancement

**Toggle enhancement on/off:**
```python
# With enhancement (default)
response = generate_with_llm(prompt, use_semantic_enhancement=True)

# Without enhancement
response = generate_with_llm(prompt, use_semantic_enhancement=False)
```
