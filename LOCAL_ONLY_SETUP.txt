================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Cannot connect to backend"
─────────────────────────────────────
Solution:
   1. Check Terminal 1 is still running
   2. Verify output says "Running on http://127.0.0.1:5000"
   3. Check no error messages in Terminal 1
   4. Restart backend if frozen


Problem: "Frontend won't load"
──────────────────────────────
Solution:
   1. Check Terminal 2 is still running
   2. Verify output says "Serving HTTP on :: port 8000"
   3. Try: http://localhost:8000/ (with trailing slash)
   4. If still 404, files may be in wrong location
   5. Verify pwd is c:\Users\johng\Documents\oscar\


Problem: Console shows "Failed to fetch"
───────────────────────────────────────
Solution:
   1. Backend likely crashed or stopped
   2. Look at Terminal 1 for error messages
   3. Common: Python process died, Redis connection failed
   4. Restart backend: python main.py in Terminal 1


Problem: "Port 8000 already in use"
──────────────────────────────────
Solution:
   Get-Process | Where-Object {$_.handles -contains 8000}
   Kill process using port 8000
   Retry: python -m http.server 8000


Problem: "Port 5000 already in use"
──────────────────────────────────
Solution:
   Get-Process -Name python* | Where-Object {$_.CommandLine -contains "5000"}
   Kill that Python process
   Retry: python main.py in backend folder
