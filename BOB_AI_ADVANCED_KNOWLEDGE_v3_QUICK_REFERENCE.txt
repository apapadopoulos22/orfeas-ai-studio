TROUBLESHOOTING
===============

Issue: "Module not found" error
Solution: Verify all 3 files are in backend/ directory

Issue: Tests fail
Solution: Run tests directly to see error details
```powershell

```

Issue: Domain not detected
Solution: Check if keywords match prompt text (case-insensitive)
- Example: "human" matches "HUMAN", "Human", "human"
