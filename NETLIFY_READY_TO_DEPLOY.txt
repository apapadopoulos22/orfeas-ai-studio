## 🔑 KEY FILES EXPLAINED

### `netlify.toml`

The master configuration file:

```toml
[build]
  publish = "."                  # Deploy current directory
  functions = "netlify/functions"# Where serverless functions are

[[redirects]]
  from = "/api/*"                # Intercept /api/* requests
  to = "/.netlify/functions/api/:splat"  # Forward to function
```

**What it does:** Tells Netlify where your files are, where to find functions, and how to route requests.

### `netlify/functions/api.js`

The API proxy function:


**What it does:** Acts as a middleman between frontend and backend, adding CORS headers and handling errors.

## 🆘 COMMON ISSUES & SOLUTIONS

### Build Fails
→ Check netlify.toml syntax
→ Verify functions directory exists
→ Review build logs in Netlify dashboard

### API Returns 502
→ Verify backend is running
→ Check BACKEND_API environment variable
→ Test backend directly: curl https://your-backend/health

### CORS Errors
→ Update CORS_ORIGINS in environment variables
→ Check netlify.toml headers section
→ Clear browser cache

### Slow Performance
→ Check backend response times
→ Monitor Netlify analytics
→ Review CDN cache settings
