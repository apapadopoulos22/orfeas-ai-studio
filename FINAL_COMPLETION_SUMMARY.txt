OLD BEHAVIOR:
  Input:  Color image
  Process: Convert to grayscale → Apply threshold → B&W
  Output: Black & White pixels (no colors)
  Result: Limited detail, lost color information

NEW BEHAVIOR:
  Input:  Color image
  Process: Luminosity threshold → Make transparent if bright
  Output: Subject with colors + transparent background
  Result: Full colors preserved, subject isolated

ALGORITHM COMPARISON:

  OLD (B&W):
    for each pixel:
      gray = grayscale(RGB)
      bw = (gray > threshold) ? white : black
      output: RGB = (bw, bw, bw), alpha = 255

  NEW (Background Removal):
    for each pixel:
      gray = grayscale(RGB)
      if gray > threshold:
        alpha = 0  (transparent - background)
      else:
        alpha = 255 (opaque - subject)
      output: RGB preserved, alpha controlled

BENEFITS:
  ✓ Colors preserved (not converted to B&W)
  ✓ Transparent background for PNG export
  ✓ Better for 3D model preparation
  ✓ Professional subject extraction
  ✓ Can use with Bob AI enhancement

UI CHANGES:
  • Button: "Generate Figurine (BW PNG)" → "Remove Background"
  • Description: "B&W colors" → "Clear background"
  • Help: Added "Lower = More kept | Higher = More removed"
  • Output: "B&W" → removed (now just colors)
