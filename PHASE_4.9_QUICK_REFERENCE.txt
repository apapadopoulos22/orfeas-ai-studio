## Common Commands

### Docker Management
```bash
# View running containers
docker ps

# View all containers
docker ps -a

# View container logs (last 20 lines)
docker logs <container-id> --tail 20

# View logs in real-time
docker logs <container-id> -f

# Stop containers
docker-compose -f docker-compose.production.yml down

# Start containers
docker-compose -f docker-compose.production.yml up -d

# Restart services
docker-compose -f docker-compose.production.yml restart

# View container stats
docker stats

# Inspect container
docker inspect <container-id>
```

### Health Checks
```bash
# API health
curl http://localhost:5000/health

# Monitoring health
curl http://localhost:8000/health

# Full system health
curl http://localhost:8000/api/health/full

# System metrics
curl http://localhost:8000/api/health/system | python -m json.tool
```

## Troubleshooting

### Services Won't Start
```bash
# Check if ports are in use
netstat -ano | findstr :5000

# Kill process using port (if needed)
taskkill /PID <pid> /F

# Verify Docker running
docker version

# Check logs
docker logs <container-id>
```

### Performance Below SLA
```bash
# Check resource usage
docker stats

# Check if container is throttled
docker inspect <container-id> | grep MemoryStats

# Review logs for errors
docker logs <container-id> --tail 50 | grep -i error

# Check specific endpoint
curl -v http://localhost:5000/api/search?q=test
```

### Health Checks Failing
```bash
# Manual health check
curl http://localhost:5000/health

# Check container status
docker ps --format "table {{.Names}}\t{{.Status}}"

# Restart service
docker-compose -f docker-compose.production.yml restart

# View health check output
docker inspect <container-id> | grep -A 20 "Health"
```
