================================================================================
                      TROUBLESHOOTING
================================================================================

If Backend Fails to Start:
  1. Check logs: docker-compose logs backend
  2. Verify requirements installed: docker-compose logs backend
  3. Restart: docker-compose restart backend
  4. Full redeploy: docker-compose down -v && python deploy_local_all_phases.py

If Frontend Not Accessible:
  1. Check NGINX: docker-compose logs frontend
  2. Verify port 8000 available: netstat -ano | findstr :8000
  3. Try alternate port in docker-compose.yml

If Docker Build Fails:
  1. Clean system: docker system prune -f
  2. Remove image: docker rmi oscar-backend
  3. Rebuild: docker-compose build --no-cache

If Services Crash:
  1. Check resources: docker stats
  2. View logs: docker-compose logs
  3. Restart all: docker-compose restart
