  TROUBLESHOOTING GUIDE

       cd backend && python main.py

Issue: CORS errors
  Check: CORS_TEST_FRONTEND.html

       Ensure browser allows file:// origin

Issue: GPU out of memory
  Fix: Reduce GPU_MEMORY_LIMIT=0.75 in .env
       Reduce MAX_CONCURRENT_JOBS=2 in .env

Issue: Slow responses
  Check: nvidia-smi (GPU stats)
  Fix: Check for competing processes
       Verify GPU_MEMORY_LIMIT setting

Issue: Logs filling up
  Check: backend/logs/ directory
  Fix: Logs auto-rotate at 10MB (enabled by default)
